1. RECONSTRUCTION OF THE FINITE TEST CATEGORY
============================================================

Ambient carrier:
U0={o1,o2,a,b,p,q,r,s}.

Equivalence classes:
K={o1,a,b,p,r,s}
L={o2,q}.

Define:
x ~ y iff x and y belong to the same one of K,L.
Define apartness:
x # y iff not(x ~ y).

Define F as the family of all subsets S subseteq U0 such that:
(i) |S| >= 2;
(ii) there exist x,y in S with x # y.

For S in F, C_S is the induced structure on S.

The category E_F is defined by:
- Objects: all C_S for S in F.
- Morphisms: all injective maps f:S -> T such that:
  x #_S y iff f(x) #_T f(y).

Equivalent formulation:
x ~_S y iff f(x) ~_T f(y).

This is a category:
- identities are injective and preserve/reflect the relation;
- composites of injective relation embeddings are injective and preserve/reflect the relation;
- associativity and identity laws follow from function composition.

2. THE SPAN
============================================================

C0 has carrier:
S0={o1,o2}.

C1 has carrier:
S1={o1,o2,a}.

C2 has carrier:
S2={o1,o2,b}.

The span maps f1:C0 -> C1 and f2:C0 -> C2 are literal inclusions.

All three objects belong to F:
- each has at least two elements;
- each contains an element of K and an element of L;
- therefore each has an apartness witness.

The maps f1,f2 are injective and preserve/reflect the induced relation. They are valid E_F morphisms.

============================================================
3. HYPOTHETICAL PUSHOUT
============================================================

Assume for contradiction that a pushout P exists in E_F, with morphisms:
j1:C1 -> P
j2:C2 -> P

satisfying the span commutativity equation:
j1 o f1 = j2 o f2.

Since j1,j2 are morphisms in E_F, both are injective and preserve/reflect equivalence/apartness.

The elements j1(a) and j2(b) are elements of the carrier of P. Equality of two elements is exhaustive, so exactly one of the following cases holds:

CASE I:
j1(a)=j2(b).

CASE II:
j1(a) != j2(b).

The proof must defeat the universal property in each case by constructing a valid cocone in E_F which cannot factor through P.

============================================================
4. CASE I — IDENTIFIED IMAGES
============================================================

Assume:
j1(a)=j2(b).

Define N' with carrier:
S_N'={p,q,r,s}.

Its induced equivalence classes are:
{p,r,s}, {q}.

N' belongs to F:
- |S_N'|=4;
- p # q, since p and q lie in different ambient equivalence classes.

Define:
g1':C1 -> N'
g1'(o1)=p
g1'(o2)=q
g1'(a)=r.

Define:
g2':C2 -> N'
g2'(o1)=p
g2'(o2)=q
g2'(b)=s.

4.1 Injectivity

The images of each map are three distinct elements:
- g1' image is {p,q,r};
- g2' image is {p,q,s}.

Thus both maps are injective.

4.2 Preservation and reflection

In C1, the equivalence classes are:
{o1,a}, {o2}.

In N', the images under g1' have classes:
{p,r}, {q}.

Therefore for every pair x,y in C1:
x ~1 y iff g1'(x) ~N' g1'(y).
Equivalently:
x #1 y iff g1'(x) #N' g1'(y).

Thus g1' is an E_F morphism.

In C2, the equivalence classes are:
{o1,b}, {o2}.

In N', the images under g2' have classes:
{p,s}, {q}.

Therefore:
x ~2 y iff g2'(x) ~N' g2'(y),
and equivalently apartness is preserved and reflected.

Thus g2' is an E_F morphism.

4.3 Agreement on the base

Both composites send:
o1 -> p
o2 -> q.

Therefore:
g1' o f1 = g2' o f2.

So (g1',g2') is a valid cocone over the original span.

4.4 Failure of factorization

If P were a pushout, there would be a morphism h':P -> N' such that:
h' o j1 = g1'
h' o j2 = g2'.

Using the assumed equality j1(a)=j2(b), these equations imply:
r
= g1'(a)
= h'(j1(a))
= h'(j2(b))
= g2'(b)
= s.

But r and s are distinct elements of N'.

Contradiction.

Therefore no factorization exists in Case I.

============================================================
5. CASE II — DISTINCT IMAGES
============================================================

Assume:
j1(a) != j2(b).

Define N with carrier:
S_N={p,q,r}.

Its induced equivalence classes are:
{p,r}, {q}.

N belongs to F:
- |S_N|=3;
- p # q.

Define:
g1:C1 -> N
g1(o1)=p
g1(o2)=q
g1(a)=r.

Define:
g2:C2 -> N
g2(o1)=p
g2(o2)=q
g2(b)=r.

5.1 Injectivity

Each map has three distinct images {p,q,r}. Both are injective.

5.2 Preservation and reflection

For g1:
- the source class {o1,a} maps to {p,r};
- the source singleton class {o2} maps to {q}.

These are exactly the equivalence classes induced on the image. Thus g1 preserves and reflects equivalence, and therefore apartness.

For g2:
- the source class {o1,b} maps to {p,r};
- the source singleton class {o2} maps to {q}.

Thus g2 also preserves and reflects equivalence and apartness.

Both are valid E_F morphisms.

5.3 Agreement on the base

Both maps send:
o1 -> p
o2 -> q.

Therefore:
g1 o f1 = g2 o f2.

So (g1,g2) is a valid cocone over the original span.

5.4 Failure of factorization

If P were a pushout, there would be a morphism h:P -> N satisfying:
h o j1 = g1
h o j2 = g2.

These equations force:
h(j1(a))=r
and
h(j2(b))=r.

But in Case II:
j1(a) != j2(b).

Thus h maps two distinct elements to the same element r. Therefore h is not injective.

Every morphism in E_F must be injective. Hence h is not a morphism in E_F.

Contradiction.

Therefore no factorization exists in Case II.

============================================================
6. CONCLUSION OF THE TWO-CASE PROOF
============================================================

The two cases:
j1(a)=j2(b)
and
j1(a)!=j2(b)
are exhaustive.

In each case, a valid cocone in E_F has been constructed for which the assumed pushout cocone admits no factorization morphism.

Therefore the assumed pushout P cannot exist.

FORMAL RESULT:

The specified span:
C1 <- C0 -> C2

has NO PUSHOUT in the explicitly defined finite fixed-carrier category E_F.

This is stronger than the statement that the particular union candidate M is not a pushout.

The proof uses:
- the exact finite ambient carrier U0;
- the exact equivalence/apartness relation;
- the exact object family F;
- the exact all-injective-apartness-embeddings morphism class;
- the exact span specified above.

No step requires a category larger than E_F. The targets N and N' are objects of F and all four maps are E_F morphisms.
