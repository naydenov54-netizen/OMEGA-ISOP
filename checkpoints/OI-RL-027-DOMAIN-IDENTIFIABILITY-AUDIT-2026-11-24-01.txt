3. MATHEMATICAL OBJECT AND EXACT CLAIMS
======================================================================

Assumptions stated in the consolidated RL record:
- H_A and H_B are finite-dimensional Hilbert spaces;
- rho_AB is a normalized bipartite density operator;
- rho_A = Tr_B(rho_AB);
- rho_B = Tr_A(rho_AB);
- Q_A(rho_AB) = Tr(rho_A^2);
- the locally available observable is O_B(rho_AB) = rho_B.

For a domain D of admissible global states, identifiability means that there exists a function
F: S(H_B) -> R
such that
Q_A(rho_AB) = F(rho_B)
for every rho_AB in D.

The record also states the equivalent fiber condition:
for all rho_AB, rho'_AB in D,
rho_B = rho'_B implies Q_A(rho_AB) = Q_A(rho'_AB).

This equivalence is valid: a function on the image O_B(D) exists exactly when Q_A is constant on every fiber of the map rho_AB -> rho_B. The function is uniquely determined on O_B(D), while its values outside O_B(D) are unconstrained.

======================================================================
4. INDEPENDENT MATHEMATICAL CHECKS
======================================================================

4.1 Pure global-state domain

For a pure bipartite state, Schmidt decomposition gives
|psi> = sum_i sqrt(lambda_i) |a_i> tensor |b_i>,
with lambda_i >= 0 and sum_i lambda_i = 1.

The reduced states have the same nonzero eigenvalues:
rho_A = sum_i lambda_i |a_i><a_i|
rho_B = sum_i lambda_i |b_i><b_i|.

Therefore:
Tr(rho_A^2) = sum_i lambda_i^2 = Tr(rho_B^2).

Thus on the pure global-state domain:
Q_A = F(rho_B), with F(X) = Tr(X^2).

CLASSIFICATION:
ESTABLISHED ANALYTICALLY under finite-dimensional bipartite quantum-state assumptions and the pure-global-state domain.

This is domain-specific. It does not establish identifiability on the full mixed-state domain.

4.2 Full mixed global-state domain

The consolidated record gives, for d_A = d_B = 2:
rho_AB(1) = |00><00|
rho_AB(2) = (1/2)|00><00| + (1/2)|10><10|.

For both states:
rho_B(1) = rho_B(2) = |0><0|.

But:
rho_A(1) = |0><0|
rho_A(2) = (1/2)(|0><0| + |1><1|).

Hence:
Q_A(1) = 1
Q_A(2) = 1/2.

The same local marginal is compatible with different subsystem purities. No function F(rho_B) can identify Q_A on the full mixed domain in this case.

The obstruction extends to every d_A >= 2 and every nonzero finite d_B by choosing any fixed pure state |b> in H_B and two distinct states on H_A with different purities, then taking product states with the same |b><b| marginal.

CLASSIFICATION:
ESTABLISHED ANALYTICALLY for the stated full mixed domain when d_A >= 2.

BOUNDARY:
If d_A = 1, Q_A is identically 1, so this non-identifiability claim does not apply. The d_A >= 2 condition is essential.

4.3 Fixed-marginal range

For fixed sigma = rho_B, choose arbitrary density operator tau on H_A and form:
rho_AB = tau tensor sigma.

Then:
rho_B = sigma
Q_A = Tr(tau^2).

For a d_A-dimensional system, the purity of tau lies in [1/d_A, 1].
Both endpoints are attained:
- tau = I/d_A gives 1/d_A;
- any pure tau gives 1.

Every intermediate value is attained, for example along the continuous family:
tau(t) = diag(t, (1-t)/(d_A-1), ..., (1-t)/(d_A-1)),
with t in [1/d_A, 1].
Its purity varies continuously from 1/d_A to 1.

Therefore:
{Q_A : rho_AB in D_all and rho_B = sigma} = [1/d_A, 1]
for d_A >= 2.

CLASSIFICATION:
ESTABLISHED ANALYTICALLY under the finite-dimensional full-state-space assumptions.

4.4 Consolidated mathematical conclusion

The core domain-bounded result is correct within the assumptions stated in the consolidated record:

- On pure global states, local rho_B determines Q_A.
- On the full mixed global domain with d_A >= 2, rho_B alone does not determine Q_A.
- At fixed rho_B, the allowed Q_A values span [1/d_A, 1].

The mathematical result does not identify a primitive information source, establish an OMEGA-specific physical mechanism, or prove a universal relation for all physical theories.

5. LOOP AUDIT
======================================================================

LOOP TARGET A:
For pure bipartite global states, Tr(rho_A^2) = Tr(rho_B^2).

L2 DEPENDENCIES:
Finite-dimensional bipartite Hilbert spaces, normalized pure state, Schmidt decomposition, partial trace, and the definition of purity.

L3 CONCLUSION SMUGGLING:
The equality is not inserted into the definition of purity or the reduced states. It follows from the common Schmidt coefficients.

L4 INDEPENDENCE:
The Schmidt decomposition independently supplies the shared nonzero spectrum.

L5 COUNTERMODEL:
No countermodel exists within the stated pure-state assumptions because the equality follows algebraically from the Schmidt form. This is a proof, not merely a failed countermodel search.

L6 PREMISE REMOVAL:
Removing the pure-state restriction invalidates the shared-spectrum argument for general mixed global states.

L7 CLASSIFICATION:
NON-CIRCULAR ANALYTICAL DERIVATION within the pure-state domain.

L8 NON-IMPLICATIONS:
No mixed-domain identifiability and no physical interpretation follow.

LOOP TARGET B:
There is no function F of rho_B alone that recovers Q_A for every state in the full mixed domain when d_A >= 2.

L2 DEPENDENCIES:
The two explicit density operators, partial traces, and purity definition.

L3 CONCLUSION SMUGGLING:
The counterexample states are specified independently of the desired conclusion.

L4 INDEPENDENCE:
Their equal rho_B and unequal Q_A are directly computed.

L5 COUNTERMODEL:
The two states form a direct counterexample to the existence of a single-valued F on the full mixed domain.

L6 PREMISE REMOVAL:
If d_A = 1, Q_A is constant and the counterexample fails. The dimension condition is necessary for this obstruction.

L7 CLASSIFICATION:
REFUTED for any claim of unrestricted mixed-domain identifiability; the negative identifiability result is established.

L8 NON-IMPLICATIONS:
This does not rule out identifiability on restricted mixed-state domains.

LOOP TARGET C:
For fixed rho_B = sigma, the attainable Q_A range is [1/d_A,1].

L2 DEPENDENCIES:
Product-state construction, finite-dimensional density-operator purity bounds, and continuity of the displayed one-parameter family.

L3 CONCLUSION SMUGGLING:
The construction fixes rho_B independently while varying tau on H_A.

L4 INDEPENDENCE:
The lower and upper bounds follow from density-operator eigenvalues; attainability follows from the explicit family.

L5 COUNTERMODEL:
No counterexample was found within the stated finite-dimensional full-state domain; the product-state family supplies all values in the interval.

L6 PREMISE REMOVAL:
Removing the full state-space/product-state admissibility or changing the subsystem dimension changes the attainable range and requires a new analysis.

L7 CLASSIFICATION:
NON-CIRCULAR ANALYTICAL DERIVATION under the stated assumptions.

L8 NON-IMPLICATIONS:
The interval is not universal outside the stated domain and definitions.

LOOP TARGET D:
Existence of F on D is equivalent to constancy of Q_A on each rho_B fiber.

L2 DEPENDENCIES:
The definition of a function and the map rho_AB -> rho_B.

L3 CONCLUSION SMUGGLING:
This is a characterization derived from single-valuedness, not an independent empirical or physical premise.

L4 INDEPENDENCE:
The two directions follow directly: a function has one value on each input; conversely, fiber constancy defines F on the image.

L5 COUNTERMODEL:
A domain containing two states with the same rho_B and different Q_A violates fiber constancy and prevents F.

L6 PREMISE REMOVAL:
If fiber constancy is removed, F need not exist.

L7 CLASSIFICATION:
NON-CIRCULAR CHARACTERIZATION, logically direct from the definition.

L8 NON-IMPLICATIONS:
This equivalence alone does not prove identifiability for any particular domain.
