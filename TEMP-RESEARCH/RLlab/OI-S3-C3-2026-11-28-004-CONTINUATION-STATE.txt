RESULT QD-2: C_R + I_R COLLAPSES QUOTIENT RELATIONS
For binary R:
C_R:
R(x,y) -> x~y

I_R:
x~x' AND y~y'
->
(R(x,y) IFF R(x',y'))

Then:
- For each equivalence class C, R restricted to C x C is either FULL or EMPTY.
- For distinct classes C,D, R restricted to C x D is EMPTY.
- Therefore:
R_bar SUBSET ID_DS

Proof:
If R(a,b) is true for a,b in C, then for any x,y in C, x~a and y~b. By I_R, R(x,y) iff R(a,b), so every pair in C x C is true. If no such pair exists, the restriction is empty. C_R excludes R between distinct classes.

For several binary relations Ri each satisfying C_Ri + I_Ri, the quotient Gaifman graph has no cross-class edges. If DS has more than one vertex, it is disconnected.

This is proved only under explicit C_R + I_R assumptions. It does not show that the full S3-C3 structure is disconnected or decomposable. The actual signature and coupling constraints remain unrecovered.

For n-ary relations, the analogous C_Rn must state that every true tuple has all coordinates in one and the same ~-class. Together with coordinatewise invariance, the relation is full or empty on C^n and has no cross-class tuple.

CONNECTIVITY CANDIDATES AND LIMITATIONS
A. Graph of apartness #:
Under A1-A3, apartness is exactly inequality of ~-classes. The graph is complete multipartite; with at least two classes it is automatically connected. This is not a useful general dependency-based decomposition criterion.

B. Quotient Gaifman graph from R:
Under C_R + I_R, R has no cross-class tuples, so the quotient graph has no cross-class edges. It does not provide nontrivial connectivity among quotient classes.

C. Hypergraph of structural dependencies:
Potentially useful only if hyperedges/supports are derived from the exact original constraints and decomposition semantics. Do not treat every # or ~ pair as a positive dependency edge; that may make connectivity vacuous.

A valid structural-connectivity criterion requires independently justified dependency/support semantics from the original S3-C3 decomposition definition.

LIMIT OF TRANSITIVE CLOSURE
Under C_R, every R-edge lies within one ~-class. Every finite R-path remains within that same class. Therefore transitive closure of R cannot create R-links between distinct quotient classes.

This excludes only transitive closure of R as a source of cross-class connectivity under C_R. It does not prove that no other alternative amalgam exists.
