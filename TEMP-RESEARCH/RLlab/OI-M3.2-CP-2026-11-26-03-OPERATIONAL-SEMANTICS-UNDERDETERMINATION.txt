==================================================
3. SEMANTIC GAP: DISTINCT OBJECT TYPES ARE COLLAPSED
==================================================

At least three mathematically distinct interpretations are compatible with the phrase "probes or interventions":

TYPE O: PASSIVE OBSERVABLE
a is represented by a measurable function f_a : X -> Y.
For a probability measure mu:
Resp_mu(a) = integral f_a(x) dmu(x).
The Markov action is K_kappa f_a.

TYPE I: DETERMINISTIC INTERVENTION
a is represented by a state transformation A_a : X -> X, together with a readout q.
For a state x:
Resp_x(a) = q(A_a(x)).
The relevant composition depends on protocol order. "Evolution then intervention" gives A_a o T at the state-map level; "intervention then evolution" gives T o A_a. These are generally different.

TYPE S: STOCHASTIC INTERVENTION
a is represented by a kernel pi_a(x,dy), together with a readout q.
For an initial measure mu:
Resp_mu(a) = integral [integral q(y) pi_a(x,dy)] dmu(x).
Combining this with system evolution requires an explicit order and kernel-composition convention.

These types are not interchangeable without additional structure. In particular, a Koopman operator acts on observables; it does not automatically act on an abstract intervention label.

==================================================
4. FINITE MARKOV COUNTERMODEL
==================================================

This model shows that even a simple, natural observable semantics does not make every restricted L_op invariant.

Let:
X = {0,1}
Sigma_X = P(X)

Define the deterministic-flip Markov kernel:
kappa(0,{1}) = 1
kappa(1,{0}) = 1

Let the initial probability measure be:
mu_p({1}) = p
mu_p({0}) = 1-p
for p in [0,1].

Choose a singleton operational language:
L_op = {a}

Represent its only probe by:
j(a) = f_a
where:
f_a(0) = 0
f_a(1) = 1.

Define the response by expectation:
Resp_mu(a) = integral f_a dmu = p.

After one Markov step:
mu_p kappa = mu_(1-p).

Therefore:
Resp_(mu_p kappa)(a) = 1-p.

Because L_op is a singleton, every map tau : L_op -> L_op must satisfy:
tau(a) = a.

H3 would require:
1-p = p
for every p in [0,1].

This is false, for example at p=0.

Operator form:
K_kappa f_a(0) = 1
K_kappa f_a(1) = 0
so:
K_kappa f_a = 1 - f_a.

But:
1 - f_a is not in j(L_op) = {f_a}.

Hence:
K_kappa(j(L_op)) is not a subset of j(L_op).

This is a finite, exact counterexample to the claim that Markov dynamics alone guarantees closure of an arbitrary restricted operational language. It is not a physical counterexample to OMEGA-ISOP.

==================================================
5. POSITIVE CONTROL: ENLARGING THE PROBE CLASS
==================================================

Keep X, kappa, and the response convention unchanged, but take:
L_op_plus = {a_0,a_1}
j(a_0) = 1_{ {0} }
j(a_1) = 1_{ {1} }.

Then:
K_kappa j(a_0) = j(a_1)
K_kappa j(a_1) = j(a_0).

Define:
tau(a_0) = a_1
tau(a_1) = a_0.

The closure condition holds and H3 follows for every initial measure mu:
Resp_(mu kappa)(a) = Resp_mu(tau(a)).

Thus the same Markov system supports:
- failure of closure for a restricted singleton probe class;
- exact closure for an enlarged two-probe class.

The decisive variable is the pair (dynamics, represented operational language), not Markov structure alone.
