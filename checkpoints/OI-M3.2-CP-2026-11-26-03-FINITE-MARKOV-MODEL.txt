3. DEFINITIONS AND NOTATION
==================================================

Finite state space:
X = {0,1}.

Two deterministic maps:
A(0)=1, A(1)=0.
B(0)=0, B(1)=0.

Thus A is the swap map and B is the reset-to-zero map.

For row-vector probability distributions p, use the convention:
p' = p K.
Every transition matrix is row-stochastic: each row sums to 1.

The corresponding matrices are:
K_A = [[0,1],[1,0]]
K_B = [[1,0],[1,0]]

Let C be the constant-one map:
C(0)=1, C(1)=1,
K_C = [[0,1],[0,1]].

Function composition f∘g means apply g first and then f. Under row-vector distributions, the matrix for f∘g is K_g K_f.

4. EXPERIMENT 01: FINITE OPERATOR SEMIGROUP
==================================================

Direct evaluation gives:
A∘A = I.
B∘B = B.
B∘A = B.
A∘B = C.

The two mixed compositions differ:
A∘B = C,
B∘A = B,
and C != B.

Therefore A and B do not commute.

The set {I,A,B,C} is closed under composition:
- I is the identity;
- A∘A=I;
- B∘B=B;
- B∘A=B;
- A∘B=C;
- compositions involving C remain in {B,C}, since B∘C=B, A∘C=B, C∘A=C, C∘B=C, and C∘C=C.

Matrix check under the declared row-vector convention:
K_B K_A = K_C, corresponding to A∘B.
K_A K_B = K_B, corresponding to B∘A.

RESULT 01:
A finite noncommutative operator semigroup is explicitly realized on X={0,1}. This is an exact algebraic result for the specified maps.

5. EXPERIMENT 02: STATE-DEPENDENT STOCHASTIC COMPOSITION
==================================================

Define a state-dependent random choice:
- At x=0: choose A with probability 0.8 and B with probability 0.2.
- At x=1: choose A with probability 0.3 and B with probability 0.7.

Evaluate the output using the actual maps:
At x=0:
A(0)=1 and B(0)=0.
Therefore P(output=0 | x=0)=0.2 and P(output=1 | x=0)=0.8.

At x=1:
A(1)=0 and B(1)=0.
Therefore P(output=0 | x=1)=1 and P(output=1 | x=1)=0.
The 0.3 probability of choosing A does NOT produce output 1, because A(1)=0.

The correct row-stochastic transition matrix is:
K_Pi = [[0.2,0.8],
        [1.0,0.0]].

Both rows sum to 1.

MATERIAL CORRECTION:
An earlier informal calculation assigned P(output=1 | x=1)=0.3. That is incorrect and is explicitly superseded here. It confused the probability of selecting A with the probability of obtaining output 1. The actual map A sends 1 to 0.

RESULT 02:
The adaptive stochastic policy induces the transition matrix above. The kernel determines the next-state distribution, but it does not, by itself, retain which operator was selected or the full intervention history.

6. EXPERIMENT 03: MEMORY AND FAILURE OF THE MARKOV PROPERTY ON X
==================================================

Define the protocol:
At time t, if x(t-1)=x(t), apply A to x(t).
Otherwise apply B to x(t).

Use the pair state:
S(t) = (x(t-1), x(t)).

The deterministic transitions are:
(0,0) -> (0,1)
(0,1) -> (1,0)
(1,0) -> (0,0)
(1,1) -> (1,0)

The projected process x(t) on X={0,1} is not Markov under this protocol.

Counterexample:
Two histories can have the same current state x(t)=0:
- History (0,0): equality holds, so A is applied and the next state is 1.
- History (1,0): equality fails, so B is applied and the next state is 0.

Thus the conditional next-state value depends on the preceding state even after the current x(t) is fixed:
P(x(t+1)=1 | x(t)=0, x(t-1)=0)=1,
P(x(t+1)=1 | x(t)=0, x(t-1)=1)=0.

Therefore the first-order Markov property fails on the projected state space X.

On the augmented state space:
X' = X × X = {(0,0),(0,1),(1,0),(1,1)},
the transition is deterministic and first-order Markov, because the next pair is a function of the current pair.

RESULT 03:
The Markov property is representation-dependent. The process is non-Markov on the insufficient projected state x(t), but Markov on the augmented state S(t)=(x(t-1),x(t)).

7. EXPERIMENT 04: MINIMAL OBSERVATION-PRESERVING REALIZATION
==================================================

Fix the deterministic protocol from Experiment 03 and define the observable output as the current component:
o(a,b)=b.

The four augmented states have outputs:
output(00)=0
output(01)=1
output(10)=0
output(11)=1

The minimal output-preserving partition is:
Q0 = {(0,0)}
Q1 = {(1,0)}
Q2 = {(0,1),(1,1)}

The quotient transitions are:
Q0 -> Q2
Q2 -> Q1
Q1 -> Q0

Why this partition is valid:
- States 01 and 11 have the same current output 1 and both transition to 10. They therefore have identical future output traces under the fixed protocol.
- States 00 and 10 both have current output 0, but their next outputs differ: 00 transitions to 01 with output 1, while 10 transitions to 00 with output 0. They cannot be merged.

Why three classes are minimal:
- Output 1 states cannot be merged with output 0 states because their current observations differ.
- The two output-0 states 00 and 10 are distinguishable by their next output.
- The two output-1 states 01 and 11 are equivalent because they have the same output and the same successor state.

Therefore exactly three equivalence classes are required for the fixed protocol and the specified output semantics.

SCOPE LIMIT:
This minimality result is specific to the fixed deterministic protocol and observation function o(a,b)=b. It does not establish a universal minimal realization across arbitrary adaptive policies, alternative output maps, or stochastic extensions.

RESULT 04:
The four-state augmented Markov model admits an exact three-state quotient preserving all future output traces for the fixed protocol.

12. LIMITATIONS AND NON-IMPLICATIONS
==================================================

This is a finite illustrative realization. Exactness inside the toy model does not imply generality outside it.

The corrected stochastic matrix is important: selection probability and output probability are not interchangeable. A selected map can send the input to an output different from the map-selection label's intuitive expectation.

The Markov property belongs to a process together with its chosen state representation. A process can fail to be Markov after projection and become Markov after state augmentation.

The three-state quotient is minimal only for the specified deterministic protocol and current-state observation. Any broader policy quantification requires a separately defined policy class and equivalence relation.
