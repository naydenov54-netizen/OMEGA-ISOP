OR-07 / RANDOM STOPPING TIME
The reviewer reports that the missing justification is supplied by the following argument:
For every admissible stopping time N with respect to the filtration generated by the observed digits and independent randomization, on {N=n} the digits after n are i.i.d. fair bits independent of the information up to n. E[L(A,theta) | F_N] >= 2^(-N).
The policy revealing all digits has cost sum_{k>=1} 4^(-k)=1/3 and zero terminal loss. It is excluded by the finite-termination requirement in §6.2. Thus non-attainment is a consequence of excluding N=+infinity.

OR-08 / RANDOMIZED MINIMAX EXAMPLE (§6.10)
Setup:
Gamma={P1,P2};
P1 is uniform on {(0,0),(1,1)};
P2 is uniform on {(0,1),(1,0)};
observe x, guess y, 0-1 loss.
A behavioral rule is q_x=P(guess=1 | x), with randomization independent of y conditional on x. The adversary chooses Q before realization of the randomization and does not observe the realized randomization.

For P1, y=x:
err1=(q0 + 1 - q1)/2.
For P2, y=1-x:
err2=(1 - q0 + q1)/2.
Thus err1+err2=1 for every q0,q1, and max(err1,err2)>=1/2.
The rule q0=q1=1/2 has error 1/2 under each distribution, so the ex-ante randomized minimax value is 1/2.
Attainment: every q0=q1 attains 1/2, including deterministic constant guesses. Therefore ex-ante randomization does not improve the deterministic ex-ante minimax value.
The pointwise-in-x conditional error probabilities under P1 and P2 also sum to 1. The conditional randomized minimax value is 1/2, attained at q_x=1/2. The conditionally re-optimized deterministic value is 1, while the ex-ante deterministic value is 1/2. These are different decision problems and must not be conflated.
The reviewer also reports minimax equality at 1/2 using the prior lambda=1/2: every rule has Bayes risk 1/2 under the equal mixture, giving maximin >=1/2, while the randomized upper bound gives minimax <=1/2.
PROPOSED TEXT: C-07′:
"Conditional on x, the error probability is P(guess != x) under P1 and P(guess = x) under P2; these sum to 1, so the conditional randomized minimax value is 1/2, attained at q_x = 1/2. Deterministic constant guesses already attain 1/2 ex ante; the discrepancy of the example is between the ex-ante deterministic value (1/2) and the conditionally re-optimized deterministic value (1)."
REVIEWER RESULT: PASS under the stated formulation; the addition is editorial. Severity LOW.

OR-09 / EXTENDED-REAL VALUES (§6.2–6.4)
The reviewer reports that v3.3 does not explicitly state the value domain for J, V_stop, and V_continue. The following cases were distinguished:
E0: Empty policy class. V=+infinity and no policy attains it.
E1: Both class values finite. The stated comparison and attainment rules apply.
E2: One class finite and the other +infinity. The finite-valued class is strictly preferable; attainment depends on whether its infimum is attained.
E3: Both values +infinity. This can mean both classes are empty or all admissible policies have J=+infinity. The comparison is degenerate and there is no finite-valued policy.
E4: One value is -infinity. The comparison is well-defined in the extended reals; by the definition of infimum there are policies below any finite threshold in that class.
E5: Both values are -infinity. Equality holds; attainment means that some policy actually has J=-infinity.
E6: J=E[loss]+E[cost] can be undefined if the two expectations have opposite infinities. A hard budget with bounded nonnegative costs can avoid this issue; otherwise the model needs a convention or stronger integrability assumptions.
E7: EVSI=R-R_e can be undefined as infinity minus infinity. The reviewer notes that the source's A6 convention addresses the case of finite R and R_e=-infinity, yielding +infinity.
The reviewer withdraws the earlier C-08 statement that attainment is not defined at -infinity. Counterexample CX-02 is reported to show that -infinity can be attained when the alternative "integrable" loss condition is used.
PROPOSED TEXT: C-08′:
"Throughout 6.3–6.4 the values V_stop and V_continue are taken in [-infinity,+infinity] with inf empty set=+infinity, and J(delta) is assumed well defined for every admissible delta (for instance because costs are nonnegative and bounded above under a hard budget). A class attains its infimum if some admissible policy has J(delta) equal to it; for the value -infinity this means J(delta)=-infinity, and 'epsilon-optimal' means J(delta) <= -1/epsilon. If both classes are empty or every admissible policy has J=+infinity, the comparison is degenerate: no admissible policy has a finite value."
REVIEWER RESULT: CONDITIONAL PASS; severity LOW.
OPEN GAP: v3.3 does not state the value domain and does not resolve E3-E6.

CX-01 — Measurability of pointwise infimum / continuation inequality
Claim attacked: A2 guarantees measurability of d -> inf_a rho_d(a), and the §6.7 inequality when R_e is defined by the lower integral of the pointwise infimum.
Construction:
H=D=[0,1], mu=Lebesgue, experiment reveals h; A=[0,1]. Let W be a Bernstein set (existence depends on the relevant set-theoretic assumptions). Define
L(a,h)=1{h != a}+1{h=a}*1{a notin W}.
For each fixed a, L(a,.) equals 1 except possibly at one point, so it is Borel and bounded. R=1. Under posterior delta_d, rho_d(a)=L(a,d), and inf_a rho_d(a)=1{d notin W}; its lower integral is 0 and upper integral is 1, so the integral is not defined as a Lebesgue integral.
For every admissible measurable rule phi for which d -> L(phi(d),d) is measurable, the zero-risk set is a measurable subset of W and hence null; rule-based risk is 1. Thus the pointwise lower-integral formulation can give a different result.
Status: reported valid, conditional on existence of a Bernstein set. Does not refute v3.3 if A4 explicitly requires measurability.

CX-02 — Attainment of -infinity
Construction:
H=D=[0,1], mu=Lebesgue; A={1,2,...}; I_n=[2^-n,2^(-n+1)); length 2^-n.
L(n,h)=-(2^n/n)*1_{I_n}(h).
For every fixed n, E[L(n,H)]=-1/n, while the rule phi(d)=n(d) that selects the interval index has total risk -sum_n 1/n=-infinity. Thus R=-1 is finite, R_e=-infinity is attained, EVSI=+infinity, and V_continue=-infinity is attained. This applies under the "integrable" alternative and shows that the prior C-08 claim was false.
