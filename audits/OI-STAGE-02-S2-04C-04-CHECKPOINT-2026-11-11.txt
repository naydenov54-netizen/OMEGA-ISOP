4. MINIMAL CATEGORICAL SPECIFICATION FORMALIZED

4.1 Objects
For the audit's minimal test framework:
C=(S_C,#_C), with S_C subseteq U0 and #_C the restricted apartness relation.
The nontriviality test additionally requires |S_C| >= 2 and an apartness witness x,y in S_C with x #_C y.
Further admissibility conditions remain realization-dependent unless separately sourced.

4.2 Parameterized morphism class
For objects C1,C2, let Emb(C1,C2) denote the injective maps preserving and reflecting apartness.
A candidate project morphism class must be specified as:
M(C1,C2) subseteq Emb(C1,C2).

The parameterization records the fact that the intended project morphism class has not yet been resolved by the sources. It does not select a preferred class.

4.3 Category axioms
For a selected object class and selected M, the minimum requirements are:
- identity morphisms belong to M(C,C);
- M is closed under composition;
- composition is associative;
- identity laws hold.

Identity maps are injective and preserve/reflect apartness.
If f:C1 -> C2 and g:C2 -> C3 are injective apartness embeddings, then g o f is injective. Moreover:
x #1 y iff f(x) #2 f(y) iff g(f(x)) #3 g(f(y)).
Thus the composite preserves and reflects apartness.
Associativity and identity laws are inherited from ordinary function composition.

This verifies the elementary category structure for the class of all such embeddings, once the object class is fixed. It does NOT establish that C_METACORE uses all such embeddings.

5. AMALGAMATION AND COLIMIT REQUIREMENTS

5.1 Amalgamation
For a span C0 --f1--> C1 and C0 --f2--> C2 in the selected category, an amalgam requires an admissible object M and morphisms j1:C1 -> M and j2:C2 -> M such that:
j1 o f1 = j2 o f2.

Existence of an amalgam is not, by itself, proof of a pushout. A pushout requires the appropriate universal property.

5.2 Colimit
A complete colimit construction requires:
- a small indexing category J;
- a functor D:J -> C_METACORE that maps identities and compositions correctly;
- a cocone eta_j:D(j) -> R satisfying eta_k o D(alpha)=eta_j for every alpha:j -> k;
- the universal property: for every compatible cocone gamma_j:D(j) -> X, there exists a unique u:R -> X such that u o eta_j=gamma_j.

The Boolean compatibility value CC(C1,C2)=1 does not, by itself, provide the category, functor, cocone, or universal property.

6.3 C_U0-EMB
Morphisms: all local injective embeddings preserving and reflecting equivalence/apartness.
General fixed-carrier AP: refuted by counterexample FC-01, recorded in S2-04C-03.
This refutation does not refute abstract C_EQ-EMB amalgamation. It refutes automatic transfer of that abstract result to the fixed-carrier all-local-embeddings category.

7. FC-01 COUNTEREXAMPLE REFERENCE

Let U0={a1,a2,a3,a4,a5,b}, with equivalence classes A={a1,a2,a3,a4,a5} and B={b}. Define apartness by x # y iff not(x ~ y).

Let C0={a1,b} and C1=C2=U0. Let f1 be the identity on C0 and let f2 swap a1 and b on C0. This is a valid local embedding: it is injective and preserves and reflects equivalence/apartness on the two-element base.

If a fixed-carrier amalgam M subseteq U0 existed with embeddings j1,j2 and commutativity, then:
p=j1(a1)=j2(b),
q=j1(b)=j2(a1),
and p != q.

The equivalence class of p would need at least five elements from the C1 copy, and the class of q at least five elements from the C2 copy. U0 contains only one equivalence class of size five and one singleton. This is impossible.
The base has |S_C0|=2, so the counterexample does not rely on a singleton-base defect.
