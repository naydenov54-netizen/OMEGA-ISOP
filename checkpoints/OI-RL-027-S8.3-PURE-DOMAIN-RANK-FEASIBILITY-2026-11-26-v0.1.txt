1. PURPOSE
==================================================

Continue S8.2 by deriving an exact nonemptiness criterion for the pure-global-state local uncertainty set. This addresses the rank(beta_B)<=d_A condition that prevents direct, unrestricted use of S7 when d_A<d_B.

No Frozen Core, canonical RL-027 record, TEST-I state, CE-V state, Volume V, or RL registry entry is modified.

==================================================
2. SETUP
==================================================

Let sigma_B be a density operator on H_B, dim(H_B)=d_B.
Let dim(H_A)=d_A and r=min(d_A,d_B).
Let p=(p_1,...,p_dB) be the eigenvalues of sigma_B, sorted:
p_1 >= p_2 >= ... >= p_dB >= 0,
sum_i p_i=1.

For eta>=0 define:
S_eta = { beta_B :
  beta_B is a density operator,
  D(beta_B,sigma_B)<=eta,
  rank(beta_B)<=d_A }.

A beta_B is realizable as the B-marginal of a pure state on H_A tensor H_B if and only if rank(beta_B)<=d_A.

By the spectral trace-distance inequality:
D(beta_B,sigma_B) >= (1/2) sum_i |q_i^downarrow-p_i|,
where q_i are the eigenvalues of beta_B. Equality is attainable by choosing beta_B commuting with sigma_B. Therefore nonemptiness can be decided spectrally.

==================================================
3. RANK-FEASIBILITY THEOREM
==================================================

THEOREM:
S_eta is nonempty if and only if

eta >= eta_rank(p,d_A)
where
eta_rank(p,d_A) = 1 - sum_{i=1}^{r} p_i,
r=min(d_A,d_B).

PROOF:

Necessity:
Take any beta_B with rank(beta_B)<=d_A. Let q be its eigenvalue vector and let S be the support of q, so |S|<=r.

For any two probability vectors p and q with q_i=0 outside S:
(1/2) sum_i |p_i-q_i|
>= sum_{i notin S} p_i.

Reason: the total absolute deficit outside S is m=sum_{i notin S}p_i. Since both vectors sum to one, the total positive excess inside S is at least m. Thus the full L1 distance is at least 2m.

Also:
sum_{i in S} p_i <= sum_{i=1}^{r}p_i,
so
sum_{i notin S}p_i >= 1-sum_{i=1}^{r}p_i.

Combining with the spectral trace-distance inequality:
D(beta_B,sigma_B)
>= 1-sum_{i=1}^{r}p_i.
Therefore eta must be at least eta_rank.

Sufficiency:
Let P_r=sum_{i=1}^{r}p_i. If P_r=0 the normalized p condition would be violated, so P_r>0.
Construct beta_B diagonal in the eigenbasis of sigma_B with eigenvalues:
q_i=p_i/P_r for i<=r,
q_i=0 for i>r.

Then rank(beta_B)<=r<=d_A, q is normalized, and beta_B commutes with sigma_B.
The total mass removed from the tail is 1-P_r. The total mass added to the first r entries is also 1-P_r. Since q_i>=p_i for i<=r:
D(beta_B,sigma_B)
= (1/2)[(1-P_r)+(1-P_r)]
=1-P_r
=eta_rank.
Thus beta_B belongs to S_eta whenever eta>=eta_rank.
QED.

==================================================
4. CONSEQUENCES
==================================================

1. If d_A>=d_B, then r=d_B and eta_rank=0. The rank condition is automatic for every B density operator.

2. If rank(sigma_B)<=d_A, then sum of the largest d_A eigenvalues is 1, so eta_rank=0. The exact fibre at eta=0 is nonempty.

3. If rank(sigma_B)>d_A, then eta_rank>0. No pure global state can have B-marginal exactly sigma_B. A nonzero local uncertainty radius is required before the pure-domain feasible set becomes nonempty.

4. The threshold is sharp. At eta=eta_rank the constructed rank-r state is feasible.

5. This is a feasibility threshold, not a formula for the minimum or maximum purity over S_eta.

==================================================
5. RANK-CONSTRAINED OPTIMIZATION: EXACT REDUCTION, NOT CLOSED FORM
==================================================

For a commuting candidate beta_B, let q be its eigenvalue vector. The pure-domain spectral problem is:

min/max sum_i q_i^2
subject to:
q_i>=0,
sum_i q_i=1,
(1/2)sum_i|q_i-p_i|<=eta,
number of nonzero q_i <= d_A.

The last condition is nonconvex. It is a union over supports S with |S|<=r.

For a fixed support S:
q_i=0 for i outside S,
q_i>=0 for i in S,
sum_{i in S}q_i=1,
(1/2)[sum_{i in S}|q_i-p_i| + sum_{i notin S}p_i] <= eta.

Each fixed-support feasible set is convex and compact. The minimum of sum q_i^2 on it is a strictly convex optimization problem with a unique minimizer. The maximum is attained at a vertex of that fixed-support polytope.

The global rank-constrained minimum and maximum are obtained by taking the minimum and maximum, respectively, over all feasible supports S. Supports of size exactly r suffice for enumeration because any smaller support can be extended to size r without changing q.

This gives an exact finite combinatorial reduction, but not yet an efficient closed-form algorithm. No claim is made that the optimal support is always the set of the r largest eigenvalues. That requires proof or counterexample.

==================================================
6. S7 DEPENDENCY
==================================================

The unrestricted S7 MIN/MAX solutions solve the spectral problem without the rank(beta_B)<=d_A restriction.

They may be used directly in the pure-global-state S8 problem only if:
(a) d_A>=d_B; or
(b) the returned optimizer is independently shown to have rank<=d_A.

If the unrestricted optimizer has rank>d_A, it is not a valid pure-global-state marginal. The rank-constrained optimization in Section 5 must be used instead.

This does not invalidate the unrestricted S7 result on its own domain. It limits the domain in which that result can be transferred to the pure-global-state S8 problem.

7. LOOP AUDIT
==================================================

L1 Definitions:
Finite dimensions, sorted spectrum, rank threshold, local trace-distance ball, and pure-state marginal feasibility are explicit.

L2 Quantifiers:
The theorem applies to every finite-dimensional sigma_B, every d_A>=1, and every eta>=0.

L3 Dependency:
Pure-state marginal rank theorem -> support-size bound -> spectral trace-distance lower bound -> top-r mass bound -> explicit commuting construction attaining the bound.

L4 Assumptions:
Density operators are normalized and positive; trace distance includes factor 1/2; finite dimensions; Schmidt rank is at most d_A.

L5 Countermodel / edge cases:
- d_A>=d_B: threshold zero.
- rank(sigma_B)<=d_A: threshold zero.
- rank(sigma_B)>d_A: exact fibre empty, as required.
- d_A=1: r=1 and threshold 1-p_1; a pure global state requires a pure B marginal, and the formula gives the exact trace-distance cost to the nearest pure spectrum.

L6 Premise removal:
Without the pure-global-state restriction, rank(beta_B)<=d_A is not required and the threshold disappears.
Without the trace-distance constraint, the nonemptiness threshold is irrelevant.

L7 Non-implications:
The theorem does not solve rank-constrained MIN/MAX.
It does not establish which support is optimal.
It does not independently validate S7 code.
It does not imply a new universal identifiability result.

L8 Scope:
Finite-dimensional bipartite quantum systems only.
