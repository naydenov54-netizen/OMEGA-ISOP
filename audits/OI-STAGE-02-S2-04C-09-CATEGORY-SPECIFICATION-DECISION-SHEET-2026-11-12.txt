3. DECISION B — MORPHISM CLASS
============================================================

Four principal candidate classes must be distinguished.

OPTION M1 — ALL LOCAL APARTNESS EMBEDDINGS

For admissible C1,C2, morphisms are all injective functions f:S1 -> S2 satisfying:
x #1 y iff f(x) #2 f(y).

Category checks:
- Identity maps satisfy the condition.
- Composites of injective apartness embeddings remain injective apartness embeddings.
- Associativity and identity laws are inherited from function composition.

Additional issue:
The object class must be fixed, and the morphism class must be closed between those objects.

Mathematical consequence:
The finite fixed-carrier category E_F in S2-04C-06 is an example of this option. For its specified span, the record contains a candidate proof of nonexistence of any pushout, subject to the internal consistency audit in Section 8 below.

Source status:
The embedding notion is source-defined, but its exhaustive identification with C_METACORE morphisms is not source-established.

OPTION M2 — LITERAL INCLUSIONS ONLY

For objects C_S,C_T, a morphism exists exactly when:
S subseteq T,
and is the literal inclusion.

Category checks:
- Identity: S subseteq S.
- Composition: S subseteq T and T subseteq V imply S subseteq V.
- Associativity and identity laws follow from inclusion composition.

Mathematical consequence:
For the declared inclusion-only category P_F, a union object is a pushout of the inclusion span when the union is an admissible object.

Limit:
This is a restricted category. A local embedding that changes elements or relabels the carrier need not be a morphism.

Source status:
No inspected authoritative source states that C_METACORE morphisms are inclusions only. The union-colimit artifact explicitly treats P_F as a restricted test category, not as the established intended category.

OPTION M3 — RESTRICTED SUBCLASS OF LOCAL EMBEDDINGS

Morphisms are a specified subclass:
M(C1,C2) subseteq Emb_#(C1,C2).

The restriction must be given by an explicit predicate P(f), for example:
f is a morphism iff f is an apartness embedding and P(f).

The predicate P cannot remain an informal phrase such as "preserves the selected structure". It must be mathematically testable.

Required checks:
- Identity closure: P(id_C).
- Composition closure: P(f) and P(g) imply P(g o f).
- Associativity and identity laws.
- Invariance of object admissibility.
- Compatibility with the intended amalgam construction.

Mathematical consequence:
This option can interpolate between all embeddings and inclusions, but its amalgamation and colimit properties must be proved for the exact predicate P. They cannot be inherited automatically from M1 or M2.

Source status:
The general language about selected structural properties is compatible with the possibility of restrictions, but no exact predicate P has been located.

OPTION M4 — RESTRICTIONS OF GLOBAL AUTOMORPHISMS

Fix the ambient structure (U0,#). A morphism C_S -> C_T is the restriction g|S of an automorphism g of (U0,#), with g(S) subseteq T.

Category checks:
- Identity automorphism gives identity maps.
- Composition of restrictions is the restriction of the composite automorphism, provided the intermediate image condition is satisfied.
- Associativity and identity laws follow from automorphism composition.

Important distinction:
Not every local apartness embedding necessarily extends to a global automorphism. Extension is an additional restriction, not a consequence of local embedding alone.

Mathematical consequence:
The earlier C_U0-AUT construction uses M=U0 as a common target. Its amalgamation argument requires U0 itself to be an admissible object in the category and the relevant inverse restrictions to be morphisms.

Source status:
No inspected authoritative source requires global automorphism extension.

OPTION COMPARISON:

M1: broadest local embedding class; fixed-carrier AP can fail in the explicit E_F test.
M2: inclusion-only; union pushout is available under admissibility closure.
M3: depends entirely on explicit P(f); no result until P is fixed.
M4: ambient-symmetry-restricted; the U0 construction is conditional on U0 being an admissible object.

No option is selected here.

4. DECISION C — AMALGAMATION INPUT
============================================================

Two mathematically distinct meanings must not be conflated.

C1. PAIR-BASED COMMON EMBEDDABILITY

Input: two objects C1,C2.

A common target consists of an object M and morphisms:
j1:C1 -> M
j2:C2 -> M.

This asks whether the two objects embed into a common admissible object. It is a joint-embedding-type condition.

C2. SPAN-BASED AMALGAMATION

Input: a specified span:
C0 --f1--> C1
C0 --f2--> C2.

An amalgam consists of an admissible object M and morphisms:
j1:C1 -> M
j2:C2 -> M

such that:
j1 o f1 = j2 o f2.

This requires the two copies of the base C0 to be identified compatibly.

The source formula CC(C1,C2) does not specify which interpretation is intended, nor does it specify a canonical common base if one is implicit.

DECISION REQUIRED:
State whether CC is pair-based or span-based. If span-based, include C0,f1,f2 in the input or define a unique rule that constructs them.

5. DECISION D — CARRIER CONVENTION
============================================================

D1. ABSTRACT CARRIER

M may be a newly constructed object, not necessarily a subset of the original U0.

Consequence:
Abstract pushout constructions may be available, but the resulting object must still satisfy the project admissibility predicate.

D2. FIXED-CARRIER REALIZATION

M must be an induced subconfiguration of the same U0:
S_M subseteq U0.

Consequence:
Abstract pushout existence does not establish fixed-carrier realizability. A separate embedding/realization theorem is required.

D3. OTHER REALIZATION RULE

A project may permit a specified class of extensions or representations. That class must be explicitly defined and shown to preserve the required structure.

DECISION REQUIRED:
Choose and formally define the carrier convention. Do not infer it from an example.

8. DECISION G — COLIMIT CLAIM
============================================================

For a candidate cocone eta_j:D(j) -> R, verify:
eta_k o D(alpha)=eta_j
for every arrow alpha:j -> k in J.

Then verify the universal property:

For every object X and every compatible cocone gamma_j:D(j) -> X, there exists a unique morphism u:R -> X such that:
u o eta_j = gamma_j
for every j in J.

The quantification over X and over all compatible cocones is essential. A common amalgam alone does not establish a pushout or a general colimit.

The universal property must be checked in the exact selected category, using its exact morphisms.
