============================================================
1. SINGLE QUESTION
============================================================

Can the assignment-relative active-exclusive connectivity
condition of S3.24 be reduced to a finite family of
assignment-independent combinatorial patterns?

Answer:
YES, for every fixed clause and fixed span, there are at
most 2^m membership patterns, where m is the number of
variable classes after quotienting by positive equality.

The exact S3.24 sufficient condition holds iff every
realizable pattern has either no active atoms or a
connected active-exclusive graph.

This is a finite-pattern characterization of the S3.24
condition. It is not a new necessary-and-sufficient
criterion for preservation of arbitrary Horn clauses.


============================================================
2. HYPOTHESES AND NOTATION
============================================================

Fix:
- a relational Horn clause;
- relational body atoms A_1,...,A_k;
- positive equality premises only;
- a free relational amalgam D of A and B over common
  induced substructure C;
- A intersect B = C;
- every clause variable occurs in at least one relational
  body atom;
- no function symbols, negative relational premises,
  disequality premises, or non-free relation additions.

Let V be the finite set of clause variables.

Let ≡ be the equivalence relation on V generated by the
positive equality premises.

Let W = V/≡ be the finite set of equality classes.

For each atom A_i, define its variable support:
supp(A_i) = { [v] in W : v occurs in A_i }.

For an assignment s satisfying the positive equality
premises, all variables in one class have the same value.

Define its outside-C pattern:
X_s = { [v] in W : s(v) is not in C }.

This is well-defined because equality-equivalent variables
have equal assigned values.

For every X subset of W, define the active atom set:
E(X) = { i : supp(A_i) intersect X is nonempty }.

Define the active-exclusive graph G_X:
- vertices are the indices in E(X);
- distinct i,j are adjacent iff
  supp(A_i) intersect supp(A_j) intersect X is nonempty.

An X-pattern is REALIZABLE if there exists an assignment
s into D such that:
1. all relational body atoms are true under s;
2. all positive equality premises are true under s;
3. X_s = X.

Write Real(X) for this predicate.


============================================================
3. FINITE-PATTERN THEOREM
============================================================

THEOREM 3.1

Under the hypotheses in Section 2, the S3.24
active-exclusive side-coherence condition holds for the
fixed span A <- C -> B iff:

For every X subset of W such that Real(X) holds:

  E(X) is empty

or

  G_X is connected.

PROOF

Take any body-satisfying assignment s.

By definition:
X_s = { equality classes assigned outside C }.

An atom A_i is C-exclusive under s exactly when at least
one of its coordinates is assigned outside C.

This is equivalent to:
supp(A_i) intersect X_s is nonempty.

Therefore:
E_s = E(X_s).

Now consider two active atoms A_i and A_j.

By the S3.24 definition, they are adjacent exactly when
some variable position in A_i and some variable position
in A_j are identified by the positive equality premises,
and their common assigned value lies outside C.

The first condition says that the two atoms share an
equality class [v] in W.

The second says [v] belongs to X_s.

Therefore:
A_i and A_j are adjacent in G_s
iff
supp(A_i) intersect supp(A_j) intersect X_s is nonempty.

Thus:
G_s = G_X_s.

Every body-satisfying assignment determines a realizable
pattern X_s. Conversely, every realizable pattern is
witnessed by at least one body-satisfying assignment.

Hence the assignment-relative S3.24 condition is
equivalent to checking E(X) and G_X for every realizable
X subset of W.

QED.


============================================================
4. FINITENESS AND COMPLEXITY BOUNDARY
============================================================

Let m = |W|.

There are exactly 2^m possible membership patterns X.

For each pattern:
- E(X) is computed from the atom supports;
- G_X is computed from intersections of finite supports;
- connectedness is a finite graph test.

Therefore the combinatorial part of the test is finite and
has at most 2^m patterns.

However, determining Real(X) is a separate constraint
satisfaction problem:
does there exist a body-satisfying assignment with exactly
the equality classes in X outside C?

For finite explicitly represented A, B and C, Real(X) can
be decided by finite assignment search or a suitable CSP
procedure.

For infinite structures, the pattern family remains
finite, but Real(X) need not be decidable by this
combinatorial reduction alone.

Therefore this theorem removes the need to construct and
inspect a separate active graph for every assignment, but
it does not eliminate the semantic feasibility question.


============================================================
5. REQUIRED ADVERSARIAL TESTS
============================================================

TEST 1 — EMPTY COMMON BASE C

If C is empty, every assigned value lies outside C.

For every body-satisfying assignment:
X_s = W.

Thus:
E(X_s) = all relational body atoms,
and G_X_s is the ordinary atom-overlap graph after
positive-equality closure.

For the transitivity body:
R(x,y) AND R(y,z),
the graph has two vertices connected through [y].

The criterion accepts the standard connected transitivity
body whenever it has a satisfying assignment.

TEST 2 — S3.22 MIXED-TRIGGER COUNTERMODEL

Body:
R(x,y) AND S(y,z).

Choose an assignment with:
s(x) outside C,
s(y) in C,
s(z) outside C.

Then:
X = { [x], [z] }.

Both atoms are active:
E(X) = {1,2}.

But:
supp(A_1) intersect supp(A_2) = { [y] },
and [y] is not in X.

Therefore G_X has two isolated vertices and is
disconnected.

The criterion correctly rejects this pattern.

TEST 3 — S3.24 NEUTRAL-INTERFACE EXAMPLE

Body:
R(x,y) AND S(y,z) AND T(x,w).

Choose:
s(x) outside C,
s(y), s(z), s(w) in C.

Then:
X = { [x] }.

The active atoms are:
E(X) = {R(x,y), T(x,w)}.

They share [x] in X, so G_X is connected.
The atom S(y,z) is neutral and is not required to join
the active graph.

The criterion accepts the assignment pattern.

TEST 4 — POSITIVE-EQUALITY BRIDGE

Body:
R(x) AND S(y) AND x=y.

There is one equality class:
q = [x]=[y].

If its assigned value lies outside C:
X={q}; both atoms are active and adjacent.

If its assigned value lies in C:
X=empty; there are no active atoms.

Both patterns satisfy the S3.24 condition.

TEST 5 — INFINITE C

The proof of Theorem 3.1 uses only membership in C and
equality classes of clause variables. It does not use
finiteness of C.

Thus the equivalence in Theorem 3.1 remains valid for
infinite C.

Only the effective determination of Real(X) may require
additional model-theoretic or algorithmic assumptions.

============================================================
6. STRICT LIMIT: THIS IS NOT NECESSITY FOR PRESERVATION
============================================================

A disconnected active-exclusive graph does not imply
failure of the Horn clause in the free amalgam.

Example:
Body:
R(x) AND S(y).

Head:
U(x) OR, in single-head Horn form, U(x).

Take a span in which all relevant body tuples and the
head witness occur in A, while B contributes no body
trigger. An assignment with x and y both outside C may
make both unary atoms active, but the active graph has
two disconnected vertices because the atoms share no
variable class.

The assignment range is nevertheless wholly in A.
Since A is a model of the clause, U(x) is true in A and
remains true in the free amalgam.

Thus the clause is preserved despite failure of
active-exclusive connectivity for that assignment.

Conclusion:
The S3.24 condition, and its finite-pattern reformulation,
remain sufficient conditions for preservation, not
necessary conditions.

A full preservation characterization must account for
whether disconnected active components can actually be
realized on opposite sides and whether the Horn head is
already supplied by a side.

7. WHAT HAS AND HAS NOT BEEN CLOSED
============================================================

CLOSED:
1. Every assignment determines one of at most 2^m
   equality-class membership patterns.
2. The active atom set depends only on the pattern.
3. The active-exclusive graph depends only on the pattern.
4. S3.24 active-exclusive side-coherence is equivalent to
   the finite realizable-pattern test.
5. The equivalence is independent of the cardinality of C.
6. Positive equality bridges are handled by quotienting
   variables by the equality-premise closure.

NOT CLOSED:
1. A span-independent syntactic characterization of which
   patterns are realizable.
2. A decision procedure for Real(X) over arbitrary
   infinite structures.
3. Necessity of active-exclusive connectivity for
   preservation.
4. A necessary-and-sufficient characterization of all
   Horn theories preserved by free amalgamation.
5. Applicability to the full canonical S3-C3 class.
