Notation:
H_A and H_B are finite-dimensional Hilbert spaces, with dimensions d_A and d_B.
rho_AB is a density operator.
rho_A = Tr_B(rho_AB), rho_B = Tr_A(rho_AB).
Q_A(rho_AB) = Tr(rho_A^2).
D(rho,sigma) = (1/2)||rho-sigma||_1.

For a reference state sigma_B and eta >= 0, define
B_eta(sigma_B) = { beta_B : beta_B is a density operator and D(beta_B,sigma_B) <= eta }.

For a global domain D, define
U_Q(D;sigma_B,eta)
= { Q_A(rho_AB) : rho_AB in D and rho_B in B_eta(sigma_B) },
and
W_Q(D;sigma_B,eta)
= sup U_Q(D;sigma_B,eta) - inf U_Q(D;sigma_B,eta),
provided the admissible set is nonempty.

W_Q is the width of the attainable purity range. It is not, by itself, a probability or an operational error bar.

1. FULL MIXED DOMAIN: EXACT RESULT

Let D_all be the set of all density operators on H_A tensor H_B.

For every fixed sigma_B and every eta >= 0, the admissible set contains all product states
rho_AB = tau_A tensor sigma_B,
where tau_A is an arbitrary density operator on H_A, because
rho_B = sigma_B and D(rho_B,sigma_B)=0 <= eta.

For these product states,
Q_A(rho_AB) = Tr(tau_A^2).

For a d_A-dimensional system, the purity of a density operator ranges over the exact interval
1/d_A <= Tr(tau_A^2) <= 1.
The lower endpoint is attained by tau_A=I_A/d_A. The upper endpoint is attained by a pure tau_A.

No density operator on A can have purity outside this interval. Therefore, for d_A >= 2,
U_Q(D_all;sigma_B,eta) = [1/d_A,1],
and
W_Q(D_all;sigma_B,eta) = 1 - 1/d_A
for every eta >= 0.

This is an exact result. Approximate knowledge of rho_B does not reduce the uncertainty in Q_A on the full mixed domain, even at eta=0. Increasing eta cannot reduce the admissible set, and the exact width remains unchanged.

2. PURE GLOBAL DOMAIN: EXACT REDUCTION TO A SPECTRAL OPTIMIZATION

Let D_pure be the set of pure states on H_A tensor H_B.

For every rho_AB in D_pure, the Schmidt decomposition implies
Q_A(rho_AB) = Tr(rho_B^2).

A density operator beta_B can occur as the B-marginal of a pure state on A tensor B if and only if
rank(beta_B) <= d_A.
This rank condition is essential when d_A < d_B.

Define the feasible local set
S_eta(sigma_B;d_A)
= { beta_B :
    beta_B is a density operator,
    D(beta_B,sigma_B) <= eta,
    rank(beta_B) <= d_A }.

If S_eta is empty, there is no pure global state in the requested local ball and W_Q is undefined for that empty admissible class.

If S_eta is nonempty, then
U_Q(D_pure;sigma_B,eta)
= { Tr(beta_B^2) : beta_B in S_eta(sigma_B;d_A) },
and
W_Q(D_pure;sigma_B,eta)
= max_{beta_B in S_eta(sigma_B;d_A)} Tr(beta_B^2)
  - min_{beta_B in S_eta(sigma_B;d_A)} Tr(beta_B^2).

The extrema exist in finite dimensions: the density-operator set is compact, the trace-distance constraint is closed, and the rank-at-most-d_A condition is closed.

At eta=0, if rank(sigma_B)<=d_A, the only feasible local state is sigma_B, hence
W_Q(D_pure;sigma_B,0)=0,
and
Q_A=Tr(sigma_B^2).
If rank(sigma_B)>d_A, the exact fibre is empty: sigma_B cannot be the marginal of a pure state on the specified A tensor B system.

3. A PRECISE CORRELATED DOMAIN: NON-PRODUCT STATES

The phrase "correlated global states" is not a mathematical domain until a condition is supplied.

One precise choice is
D_nonprod = { rho_AB : rho_AB is a density operator and rho_AB != rho_A tensor rho_B }.

In finite dimensions, this is equivalently the set of states with strictly positive quantum mutual information:
I(A:B)_rho = S(rho_A)+S(rho_B)-S(rho_AB) > 0.
This definition imposes nonzero correlation but no positive lower bound on its magnitude.

The following exact-width result holds.

Proposition:
Assume d_A>=2 and rank(sigma_B)>=2. For every eta>=0,
sup U_Q(D_nonprod;sigma_B,eta) - inf U_Q(D_nonprod;sigma_B,eta)
= 1 - 1/d_A.

Proof:
Let P_B be the support of sigma_B. On P_B, sigma_B is strictly positive. Since rank(sigma_B)>=2, there exists a nonzero traceless Hermitian operator Y_B supported on P_B. Since d_A>=2, there exists a nonzero traceless Hermitian operator X_A on H_A.

For the lower endpoint, choose tau_A=I_A/d_A and define
rho_AB(t) = (I_A/d_A) tensor sigma_B + t X_A tensor Y_B.
The partial traces of X_A and Y_B vanish, so
rho_A(t)=I_A/d_A,
rho_B(t)=sigma_B.
For sufficiently small nonzero real t, rho_AB(t) remains positive: the unperturbed product state is strictly positive on H_A tensor P_B, and positivity is stable under sufficiently small Hermitian perturbations on that support. The state is normalized because the perturbation is traceless. It is not a product state because its nonzero correlation term X_A tensor Y_B cannot be absorbed into the product of its unchanged marginals.
Consequently,
Q_A(rho_AB(t))=1/d_A.
Thus the lower endpoint is attained inside D_nonprod while the local marginal is exactly sigma_B.

For the upper supremum, choose a full-rank sequence tau_A(epsilon) whose purity tends to 1 as epsilon tends to 0+, for example
tau_A(epsilon) = (1-epsilon)|0><0| + epsilon/(d_A-1) sum_{j=1}^{d_A-1}|j><j|,
with 0<epsilon<1.
For each fixed epsilon, tau_A(epsilon) tensor sigma_B is strictly positive on H_A tensor P_B. Using the same nonzero traceless X_A and Y_B, choose a sufficiently small nonzero t_epsilon so that
rho_AB(epsilon) = tau_A(epsilon) tensor sigma_B + t_epsilon X_A tensor Y_B
is a density operator.
Its marginals remain tau_A(epsilon) and sigma_B, and it is non-product. Therefore
Q_A(rho_AB(epsilon))=Tr(tau_A(epsilon)^2) -> 1.
The global upper bound Q_A<=1 shows that the supremum over D_nonprod is exactly 1, although it is not attained: a pure marginal rho_A forces every bipartite state to factorize across A:B.

Combining the attained infimum 1/d_A with the supremum 1 gives the claimed width.
Because rho_B=sigma_B exactly in both constructions, they belong to every eta-ball with eta>=0. QED.

Important qualification:
If rank(sigma_B)=1, no correlated state can have that pure marginal: every global state with a pure reduced state on B is a product across A:B. In that case the fibre of D_nonprod over sigma_B is empty. If rank(sigma_B)>=2, the proposition applies.

Interpretation:
Merely requiring nonzero correlations does not improve local identifiability or local stability. Arbitrarily weak nonzero correlations can preserve the same local marginal while allowing Q_A to approach its full-domain supremum and attain its minimum. A quantitative correlation-strength restriction would be a different problem.

4. STRONGER CORRELATION RESTRICTIONS: NOT SOLVED HERE

Examples of genuinely stronger, mathematically precise domains include:
D_I(kappa) = {rho_AB : I(A:B)_rho >= kappa},
for a specified kappa>0; or
D_C(c) = {rho_AB : ||rho_AB-rho_A tensor rho_B||_1 >= c},
for a specified c>0.

These are not equivalent constraints. Their feasible fibres depend on dimensions, the fixed local marginal, and the chosen threshold. No claim is made here that their Q_A widths equal the non-product width, nor that they admit a universal formula. They require separate analysis and feasibility checks.

A fixed-global-purity domain
D_P = {rho_AB : Tr(rho_AB^2)=P}
is another precise restriction, but it is not synonymous with a correlation constraint: product states can belong to it.
