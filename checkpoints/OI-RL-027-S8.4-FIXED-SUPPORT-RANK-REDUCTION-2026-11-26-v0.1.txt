==================================================
1. PURPOSE AND CORRECTION
==================================================

This checkpoint sharpens the rank-constrained formulation in S8.3.

S8.3 Section 5 described a union over possible supports and left open whether an optimal support could always be chosen among the largest eigenvalues. For the spectral trace-distance problem, that open question is resolved by sorting the spectra and applying the trace-distance eigenvalue inequality. The rank constraint can be imposed directly as zero tail entries in the sorted candidate spectrum. No combinatorial support search is needed for the spectral optimization.

This correction does not change the rank-feasibility threshold in S8.3.

==================================================
2. EXACT SPECTRAL REDUCTION
==================================================

Let sigma_B have eigenvalues sorted:
p_1 >= p_2 >= ... >= p_dB >= 0,
sum_i p_i=1.

Let r=min(d_A,d_B).

For any candidate beta_B, let q_1 >= ... >= q_dB >=0 be its sorted eigenvalues. The trace-distance eigenvalue inequality gives:
(1/2)sum_i |p_i-q_i| <= D(sigma_B,beta_B).

If beta_B is feasible for the local trace-distance ball, then:
(1/2)sum_i |p_i-q_i| <= eta.

If beta_B is also a possible marginal of a pure state on A tensor B, then rank(beta_B)<=d_A, hence:
q_{r+1}=...=q_{dB}=0.

Conversely, take any probability vector q satisfying:
q_1>=...>=q_r>=0,
q_{r+1}=...=q_{dB}=0,
(1/2)sum_i |p_i-q_i|<=eta.

Construct beta_B diagonal in an eigenbasis of sigma_B, with diagonal entries q_i in the same sorted order. Then beta_B commutes with sigma_B, has rank at most r<=d_A, and:
D(beta_B,sigma_B)=(1/2)sum_i|p_i-q_i|<=eta.

Therefore the set of attainable purity values in the pure-global-state local ball is exactly the set generated by this sorted spectral feasible set. In particular, both extrema can be computed by optimizing sum_i q_i^2 over it.

==================================================
3. FIXED TOP-r SUPPORT FORMULATION
==================================================

The exact rank-constrained spectral problem is:

F_r(p,eta) = {
q in R^dB :
q_i>=0,
sum_i q_i=1,
q_{r+1}=...=q_dB=0,
(1/2)sum_i |q_i-p_i|<=eta
}.

Then:
Q_min^pure = min_{q in F_r(p,eta)} sum_i q_i^2,
Q_max^pure = max_{q in F_r(p,eta)} sum_i q_i^2.

The sortedness condition q_1>=...>=q_r may be included without changing the extrema. It is not necessary for the convex formulation if q is interpreted as a diagonal candidate in the fixed eigenbasis; any feasible q vector is itself a valid commuting density operator. For a canonical spectral representative, sort q and use the eigenvalue inequality/rearrangement argument.

F_r is a convex compact polytope:
- nonnegative orthant;
- affine normalization;
- fixed zero tail;
- an L1-ball constraint.

Consequences:
- The MIN objective is strictly convex, so the minimizer is unique.
- The MAX objective is convex, so a maximum is attained at a vertex of F_r.
- The optimization is now a fixed-support problem, not a combinatorial union over supports.

==================================================
4. FEASIBILITY THRESHOLD CONSISTENCY
==================================================

The minimum possible trace distance to any rank-r spectrum is:
eta_rank = 1 - sum_{i=1}^r p_i.

Necessity follows because q_i=0 for i>r, so at least the tail mass must be removed.
Sufficiency is attained by:
q_i=p_i/P_r for i<=r,
q_i=0 for i>r,
where P_r=sum_{i=1}^r p_i.

Thus:
F_r(p,eta) is nonempty iff eta>=eta_rank.

This agrees exactly with S8.3.

==================================================
5. WHAT THIS DOES AND DOES NOT SOLVE
==================================================

Established:
- The rank-constrained pure-domain spectral problem reduces exactly to a single fixed top-r support.
- No enumeration over arbitrary supports is needed.
- The feasible set is convex and compact.
- MIN has a unique optimizer.
- MAX is attained at a vertex.
- The exact nonemptiness threshold remains eta_rank.

Not yet established:
- A closed-form water-filling expression for rank-constrained MIN.
- A closed-form or efficient exact vertex characterization for rank-constrained MAX.
- Whether the unrestricted S7 optimizer automatically respects rank<=d_A in any additional parameter regimes beyond those directly checked.
- Independent execution of the supplied S7 script.

Important distinction:
This fixed-support problem is not identical to the unrestricted S7 problem when d_A<d_B. The zero-tail constraints remain active and must not be dropped.

==================================================
6. LOOP AUDIT
==================================================

L1 Definitions:
Sorted p and q spectra, rank r, trace distance, and fixed-support feasible set are explicit.

L2 Quantifiers:
The reduction holds for every finite d_A,d_B and every eta for which the feasible set is nonempty.

L3 Dependency:
Spectral trace-distance inequality gives a feasible sorted q; pure-state marginal rank bounds its support; commuting construction proves converse attainability.

L4 Assumptions:
Finite dimensions; density operators; trace distance convention includes factor 1/2; pure-state marginal rank theorem.

L5 Countermodel / edge cases:
If d_A>=d_B, r=d_B and the zero-tail restriction disappears.
If eta<eta_rank, no pure global state lies in the local ball.
At eta=eta_rank, the normalized top-r truncation construction is feasible.

L6 Premise removal:
Without pure global states, rank(beta_B)<=d_A is not required.
Without trace-distance control, the local feasible set is not restricted by eta.

L7 Non-implications:
This reduction does not prove unrestricted S7 formulas solve the rank-constrained problem.
It does not give closed-form extrema.
It does not alter RL-027 core identifiability claims.

L8 Scope:
Finite-dimensional bipartite quantum states only.
