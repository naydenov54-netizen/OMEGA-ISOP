# Audit Records

Use this directory for review records that assess mathematical derivations, assumptions, reproducibility, and consistency with the project's governing rules.

Each audit should identify:

- the exact artifact and version reviewed;
- the claims and assumptions examined;
- calculations or checks performed;
- issues, limitations, and unresolved questions;
- the audit conclusion and its scope.

An audit record must not silently modify the artifact under review. Keep corrections in a separate proposed revision until approved. Do not infer registration status from an audit or from repository activity.
