2. FORMAL SETUP

Assume:
- X is a nonempty set;
- I is an index set;
- for every i in I, V_i is a set;
- for every i in I, f_i : X -> V_i is a total function.

Define:
F : X -> product_{i in I} V_i
by F(x) = (f_i(x))_{i in I}.

Define D : X x X -> {0,1} by:
D(x,y) = 1 iff F(x) != F(y);
D(x,y) = 0 iff F(x) = F(y).

By extensionality of the Cartesian product:
F(x) = F(y) iff for all i in I, f_i(x) = f_i(y).

Equivalently:
D(x,y) = 1 iff there exists i in I such that f_i(x) != f_i(y).

3. TRIANGLE INEQUALITY

Claim:
For all x,y,z in X,
D(x,y) <= D(x,z) + D(z,y).

Proof by cases.

Case 1: D(x,y) = 0.

Then F(x) = F(y). For every z:
F(x) = F(z) iff F(y) = F(z).

Therefore D(x,z) = D(y,z). By symmetry, D(y,z) = D(z,y). Hence:
D(x,y) = 0 <= D(x,z) + D(z,y).

In fact, the stronger identity holds:
D(x,y) = 0 implies D(x,z) = D(y,z) for every z in X.

Case 2: D(x,y) = 1.

Suppose, for contradiction, that D(x,z) + D(z,y) = 0.
Since both terms belong to {0,1}, this implies:
D(x,z) = 0 and D(z,y) = 0.

Thus:
F(x) = F(z) and F(z) = F(y),
so F(x) = F(y), contradicting D(x,y) = 1.

Therefore:
D(x,z) + D(z,y) >= 1 = D(x,y).

Both cases establish the triangle inequality.

4. PSEUDOMETRIC AXIOMS

Nonnegativity:
D(x,y) belongs to {0,1}, hence D(x,y) >= 0.

Symmetry:
F(x) != F(y) iff F(y) != F(x), hence D(x,y) = D(y,x).

Zero diagonal:
F(x) = F(x), hence D(x,x) = 0.

Triangle inequality:
Established in Section 3.

Conclusion:
D is a pseudometric on X.

5. METRICITY CRITERION

Claim:
D is a metric on X if and only if F is injective.

Forward direction:
Assume D is a metric. Its separation axiom gives:
D(x,y) = 0 implies x = y.

By definition of D:
F(x) = F(y) iff D(x,y) = 0.

Therefore F(x) = F(y) implies x = y, so F is injective.

Reverse direction:
Assume F is injective.
If D(x,y) = 0, then F(x) = F(y).
Injectivity gives x = y.
Thus the separation axiom holds. All other metric axioms were established in Section 4.

Therefore:
D is a metric on X iff F is injective.

6. EMPTY-INDEX CASE

Under the standard convention:
product_{i in emptyset} V_i = {emptyset},
the singleton set containing the empty function.

There is exactly one function F : X -> {emptyset}; it is constant.
Consequently D(x,y) = 0 for all x,y in X.

The triangle inequality reduces to:
0 <= 0 + 0.

F is injective exactly when X has at most one element. Since X is assumed nonempty:
F is injective iff |X| = 1.

Therefore, in the empty-index case:
D is a metric iff |X| = 1;
if |X| > 1, D is a pseudometric but not a metric.

No assumption I != emptyset is needed for the triangle inequality or for the general metricity criterion.
