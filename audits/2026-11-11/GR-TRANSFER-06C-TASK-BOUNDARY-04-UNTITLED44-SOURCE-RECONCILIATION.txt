SOURCE-LEVEL CALL CHAIN

A. SET MOVE
InclRect2Set::move(DiffIncl& diffIncl):
- stores x = VectorType(*this);
- stores currentTime = getCurrentTime();
- calls BaseSet::move(diffIncl.getDynamicalSystem());
- computes Delta = diffIncl.perturbations(currentTime,x);
- updates the set representation and adds Delta to m_currentSet.

Thus the unperturbed selected ODE propagation is performed first. The differential-inclusion perturbation is then bounded using the original pre-step time and state.

B. BASE DOUBLETON MOVE
C0DoubletonSet::move(dynsys,result):
- calls dynsys.encloseC0Map(getCurrentTime(), ...);
- computes the new doubleton representation from the validated Taylor image, Jacobian, remainder and enclosure;
- sets result current time to getCurrentTime() + dynsys.getStep().

The time update is therefore explicitly based on the step value actually held by the underlying ODE solver after encloseC0Map returns.

C. SETSTEP SEMANTICS
BasicOdeSolver::setStep(newStep):
- assigns m_fixedTimeStep = newStep;
- calls turnOffStepControl().

BasicOdeSolver::computeTimeStep():
- when step control is off, assigns m_step = min(m_fixedTimeStep, getMaxStep()).

DiffInclusion::setStep(newStep) delegates to m_dynamicalSystem.setStep(newStep).

Therefore solver.setStep(eta) does not merely suggest an adaptive maximum step. In this release source it sets the fixed step and disables adaptive step control.

D. MAXIMUM-STEP AND REMAINDER PATH
computeAndApproveRemainder():
- temporarily saves step-control state;
- bounds maxStep by min(maxStep, 2*current step) when the step is nonsingular;
- calls solver.computeTimeStep(...);
- computes the Taylor remainder;
- only enters its remainder-size loop for step reduction when isStepChangeAllowed() is true.

Because setStep() disables step control, that adaptive reduction loop is not enabled by this call path.

HighOrderEnclosure:
- constructs h = [0,1]*ds.getStep();
- computes the Taylor polynomial range over h;
- predicts an enclosure using the next remainder coefficient;
- recomputes remainder coefficients on the predicted enclosure;
- checks the required interior inclusion for the remainder;
- if step change is disabled and inclusion fails, refines the enclosure and retries up to 30 times;
- throws an error if it cannot establish the enclosure.

This means a successful fixed-step enclosure is not silently converted into a smaller adaptive step by this HighOrderEnclosure branch. Failure is expected to raise an exception after the prescribed refinement attempts.

E. FIRST-ORDER ENCLOSURE FOR THE DIFFERENTIAL INCLUSION
DiffInclusion::diffInclusionEnclosure(t,x) calls:
FirstOrderEnclosure::enclosure(m_diffIncl,t,x,getStep()).

The inspected FirstOrderEnclosure implementation forms:
h = [0,1]*step
timeRange = currentTime + h

It evaluates the interval vector field on timeRange and a trial state box, then iterates:
y = x + h * vectorField(timeRange,z)
until y is contained in the interior of z, or throws a SolverException after the bounded search.

The source comments identify this as an enclosure of the solution over the whole time step. This is the enclosure path used for W2 in DiffInclusionCW.

F. COMPONENT-WISE PERTURBATION BOUND
DiffInclusionCW::perturbations(time,x):
- W1 = dynamicalSystemEnclosure(time,x)
- W2 = diffInclusionEnclosure(time,x)
- J = m_diffIncl.derivative(time,W2)
- delta = m_diffIncl.perturbations(time,W1)
- requires delta to contain zero, otherwise throws;
- constructs C from an outward upper bound on abs(delta);
- forms At = getStep()*J;
- sums a matrix series with an explicit geometric remainder estimate;
- forms D = getStep()*(Sum*C);
- returns symmetric component intervals [-D_i.rightBound(), D_i.rightBound()].

The resulting Delta is then added to the unperturbed set enclosure by InclRect2Set::move().
