1. RESULT AR-01-A — QUOTIENT PROJECTION AS COEQUALIZER IN Set
================================================================

1.1 PREMISES AND DEFINITIONS

Let X be a set and let ~ be an equivalence relation on X.

Define the relation-object:
E = {(x,y) in X x X : x ~ y}.

Let p1,p2 : E -> X be the coordinate projections:
p1(x,y)=x,
p2(x,y)=y.

Let Q = X/~ be the quotient set and define:
q : X -> Q,
q(x)=[x].

The quotient set exists in ZF: each equivalence class is a subset of X, and Q is the image of X under the class map x -> [x], obtained by Replacement. No Axiom of Choice is required.

1.2 COEQUALIZING PROPERTY

For every (x,y) in E, x~y. Hence [x]=[y], so:
q(p1(x,y)) = q(p2(x,y)).

Therefore:
q o p1 = q o p2.

1.3 UNIVERSAL PROPERTY

Let Z be any set and let g : X -> Z be a function satisfying:
g o p1 = g o p2.

This equality means that for every (x,y) in E:
g(x)=g(y).

Define:
h : Q -> Z
by:
h([x])=g(x).

WELL-DEFINEDNESS

Suppose [x]=[y]. Since ~ is an equivalence relation:
x~y.
Thus (x,y) belongs to E. By the assumed equality on the two projections:
g(x)=g(y).

Therefore h assigns the same value to every representative of a given equivalence class. Hence h is well-defined.

FACTORISATION

For every x in X:
(h o q)(x)=h([x])=g(x).

Therefore:
g = h o q.

UNIQUENESS

Suppose h1,h2 : Q -> Z both satisfy:
g=h1 o q=h2 o q.

For any C in Q, by definition of the quotient there exists x in X with C=[x]=q(x). Hence:
h1(C)=h1(q(x))=g(x)=h2(q(x))=h2(C).

Thus h1=h2.

1.4 CONCLUSION

The quotient projection q : X -> X/~ is a coequalizer in Set of the kernel-pair projections p1,p2 : E -> X.

The universal property is:
g o p1 = g o p2
iff there exists a unique h : X/~ -> Z such that
g = h o q.

The forward implication is the universal factorization proved above. The reverse implication follows from q o p1=q o p2.

STATUS: PROVED.

SCOPE LIMIT:
This is the standard quotient/coequalizer property of a set under an equivalence relation. It does not establish a physical, dynamical, causal, or ontological interpretation of the quotient.

2. RESULT AR-01-B — UNIQUENESS UP TO ISOMORPHISM OF SIGNATURE IMAGES
================================================================

2.1 PREMISES

Let X be a set and let:
F1 : X -> A,
F2 : X -> B
be functions into sets A and B.

Define:
D1(x,y)=0 iff F1(x)=F1(y),
D1(x,y)=1 iff F1(x)!=F1(y),

and:
D2(x,y)=0 iff F2(x)=F2(y),
D2(x,y)=1 iff F2(x)!=F2(y).

Assume:
D1 = D2 on X x X.

Write F1(X) and F2(X) for the images.

2.2 DEFINITION OF THE IMAGE MAP

Define:
h : F1(X) -> F2(X)
by:
h(F1(x))=F2(x).

2.3 WELL-DEFINEDNESS

Suppose F1(x)=F1(y).

Then D1(x,y)=0. Since D1=D2:
D2(x,y)=0.

Therefore:
F2(x)=F2(y).

Hence the value F2(x) depends only on F1(x), and h is well-defined.

2.4 INJECTIVITY

Suppose:
h(F1(x))=h(F1(y)).

By definition:
F2(x)=F2(y).

Thus D2(x,y)=0. Since D1=D2:
D1(x,y)=0.

Therefore:
F1(x)=F1(y).

Hence h is injective.

2.5 SURJECTIVITY

Let v be any element of F2(X).

By the definition of image, there exists x in X such that:
v=F2(x).

By definition of h:
v=h(F1(x)).

Therefore h is surjective onto F2(X).

2.6 UNIQUENESS

Suppose k : F1(X) -> F2(X) also satisfies:
k(F1(x))=F2(x)
for every x in X.

Every element u of F1(X) has the form u=F1(x) for some x. Thus:
k(u)=F2(x)=h(u).

Therefore k=h.

2.7 ISOMETRY

Equip F1(X) and F2(X) with their respective restricted discrete metrics:
delta1(u,v)=0 iff u=v, otherwise 1;
delta2(s,t)=0 iff s=t, otherwise 1.

For all x,y in X:
F1(x)=F1(y) iff D1(x,y)=0
iff D2(x,y)=0 iff F2(x)=F2(y).

Consequently:
delta1(F1(x),F1(y)) = delta2(F2(x),F2(y)).

Every pair of elements of F1(X) has representatives F1(x),F1(y). By the definition of h:
delta1(u,v)=delta2(h(u),h(v)).

Thus h preserves distances. Since h is bijective, it is an isometry.

2.8 CONCLUSION

If D1=D2 on X x X, there exists exactly one bijection:
h : F1(X) -> F2(X)
such that:
h o F1 = F2,
where F1 and F2 in this equation are regarded as corestricted maps into their images.

With the restricted discrete metrics, h is an isometry.

STATUS: PROVED.

IMPORTANT NON-CLAIMS

The theorem does not establish:
- uniqueness of F1 or F2 as representations;
- equality of the codomains A and B;
- a preferred feature family;
- physical or ontological canonicality;
- equivalence of D with PD or Frozen Core relation R;
- universality across an unspecified class of admissible representations;
- a universal OMEGA-ISOP theorem.

The exact conclusion is uniqueness of the isomorphism between the two signature images, relative to the premise D1=D2.
