1. PURPOSE

This note sharpens OPEN-1 from the final external audit: a general necessary-and-sufficient characterization of identifiability for an arbitrary allowed state set H.

It fixes the comparison class and cardinalities explicitly and gives an exact finite combinatorial criterion. It does not claim a cardinality-independent closed-form classification for all H, nor does it replace the controlled RL-021.1 source.

2. FIXED SETTING

Let B and X be fixed finite disjoint sets with:
m = |B| >= 1,
n = |X| >= 1.

For each x in X define:
O_x = {b in B : (b,x) belongs to R},
I_x = {b in B : (x,b) belongs to R}.

The allowed state condition is:
(|O_x|, |I_x|) belongs to H for every x in X.

Only realizable states can occur. Therefore define:
H_m = H intersect ({0,1,...,m} x {0,1,...,m}).

The observation is the complete labelled boundary degree profile:
D_B(R) = ((r_b,s_b))_{b in B},
where:
r_b = sum over x in X of 1[b in O_x],
s_b = sum over x in X of 1[b in I_x].

The target is:
Q_B(R) = 1 iff there exists x in X such that O_x is nonempty and I_x is nonempty.

All quantifiers below range over every relation whose external incidence sets satisfy the stated per-x H constraint. Relations inside B x B and X x X are unrestricted and irrelevant to this observation and target.

Assume the resulting comparison domain is nonempty.

3. LOCAL CONFIGURATION CLASSES

Define C_0(H,B) as the set of pairs (O,I) of subsets of B such that:
(|O|,|I|) belongs to H_m,
and (O is empty or I is empty).

Define C_1(H,B) as the set of pairs (O,I) of subsets of B such that:
(|O|,|I|) belongs to H_m,
and O and I are both nonempty.

A relation has Q_B=0 exactly when every x in X uses a configuration from C_0.

A relation has Q_B=1 exactly when at least one x in X uses a configuration from C_1 and every other x uses a configuration from C_0 union C_1.

4. PROFILE SETS

For an ordered n-tuple ((O_x,I_x)) indexed by X, define its profile p by:
p = ((r_b)_{b in B}, (s_b)_{b in B}),
with r_b and s_b as in Section 2.

Let P_0(H;m,n) be the set of all profiles generated by n-tuples from C_0(H,B).

Let P_1(H;m,n) be the set of all profiles generated by n-tuples from C_0(H,B) union C_1(H,B), with at least one coordinate in C_1(H,B).

These are finite, explicitly enumerable sets.

5. THEOREM — EXACT FINITE-CARDINALITY CRITERION

For the fixed finite labelled sets B and X and the per-external-node allowed-state condition H:

D_B identifies Q_B on the stated comparison domain if and only if:
P_0(H;m,n) intersect P_1(H;m,n) is empty.

Equivalently, identifiability fails if and only if there exists one labelled degree profile p that is realizable both:
(a) by a relation with no external node carrying both incoming and outgoing boundary incidence; and
(b) by a relation with at least one external node carrying both types of incidence.

PROOF

By definition, every admissible relation determines one configuration (O_x,I_x) for each x in X. Its degree profile is the coordinatewise sum of the indicator vectors of these configurations.

First, Q_B=0 holds exactly when every coordinate configuration belongs to C_0. Hence the profiles of all Q_B=0 relations are exactly P_0.

Second, Q_B=1 holds exactly when at least one coordinate belongs to C_1, while every coordinate belongs to C_0 union C_1. Hence the profiles of all Q_B=1 relations are exactly P_1.

By the definition of identifiability, D_B identifies Q_B precisely when no two admissible relations with the same D_B profile have different Q_B values.

Such a pair exists precisely when a profile belongs to both P_0 and P_1.

Therefore D_B identifies Q_B if and only if P_0 intersect P_1 is empty. QED.

6. GENERATING-POLYNOMIAL FORM

For each configuration (O,I), define its monomial:
z(O,I) = product over b in O of u_b, multiplied by product over b in I of v_b.

Define:
A_0 = sum of z(O,I) over (O,I) in C_0(H,B),
A_1 = sum of z(O,I) over (O,I) in C_1(H,B),
A = A_0 + A_1.

The ordinary polynomial A_0^n counts all ordered n-coordinate configurations with Q_B=0, by degree-profile exponent vector.

The polynomial:
A^n - A_0^n
counts all ordered n-coordinate configurations with Q_B=1, by degree-profile exponent vector.

All coefficients in A^n - A_0^n are nonnegative integers.

Let Supp(P) denote the exponent vectors whose coefficients in polynomial P are nonzero.

The theorem is equivalently:
D_B identifies Q_B if and only if
Supp(A_0^n) intersect Supp(A^n - A_0^n) is empty.

This gives a finite exact decision procedure for each fixed finite pair (m,n) and each explicitly supplied H.

7. BOUNDARY CHECKS AND EXAMPLES

7.1 One external node

If n=1, the profile records the indicator vectors of O_x and I_x exactly. Therefore it determines whether both sets are nonempty.

Thus for n=1, D_B identifies Q_B for every nonempty allowed-state class H.

7.2 Only one-sided allowed states

If every state in H_m satisfies o=0 or i=0, then C_1 is empty, Q_B is identically zero, and D_B identifies Q_B.

7.3 Only jointly incident allowed states

If every state in H_m has o>0 and i>0, then for n>=1 every admissible relation has Q_B=1. The target is constant and is identifiable.

7.4 Degenerate example H={(1,0)}

For m>=1 and n>=1, every external node has no incoming boundary incidence. Hence Q_B is identically zero. Identifiability holds, despite the presence of an unpaired outgoing state.

7.5 Unrestricted state class

Let H contain every pair (o,i) with 0<=o,i<=m. For m>=1 and n>=2, choose b in B and distinct x_1,x_2 in X.

Q_B=0 realization:
O_x1={b}, I_x1=empty;
O_x2=empty, I_x2={b};
all remaining configurations empty.

Q_B=1 realization:
O_x1={b}, I_x1={b};
all remaining configurations empty.

Both realizations have the same profile: r_b=1, s_b=1, and all other profile entries zero. Their target values differ.

Thus D_B is not identifying for the unrestricted class when n>=2, consistently with the existing RL-021.1 result.

8. WHAT THIS RESULT DOES AND DOES NOT CLOSE

Established by this note, if the proof and definitions are accepted:
- an exact necessary-and-sufficient finite combinatorial criterion for each fixed finite m,n and arbitrary per-node state set H;
- explicit treatment of labelled degree profiles and realizability;
- a finite enumeration / generating-polynomial decision procedure;
- recovery of the known degenerate, one-sided, jointly incident, n=1, and unrestricted examples.

Not established:
- a simpler closed-form classification independent of m and n;
- a characterization when m or n is infinite;
- a characterization for allowed classes with cross-node constraints not expressible as independent per-x membership in H;
- a criterion for observations other than the complete labelled D_B profile;
- any physical, causal, or dynamical interpretation of Q_B.
