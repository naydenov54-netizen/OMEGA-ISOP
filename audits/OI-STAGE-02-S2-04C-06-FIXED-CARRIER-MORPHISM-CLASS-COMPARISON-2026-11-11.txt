2. EXPLICIT FIXED-CARRIER REALIZATION
============================================================

Fix one finite carrier:

U0 = {o1,o2,a,b,p,q,r,s}.

Define one equivalence relation ~ on U0 by its classes:

K = {o1,a,b,p,r,s}
L = {o2,q}.

Thus:
x ~ y iff x and y belong to the same one of K or L.

Define apartness by:
x # y iff not(x ~ y).

For this finite test realization, define F to be the family of all subsets S of U0 satisfying:
(1) |S| >= 2;
(2) there exist x,y in S with x # y.

For each S in F, let:
C_S = (S, # restricted to S x S).

IMPORTANT SCOPE:
The above F is an explicit test object class. The nontriviality test is adopted as a condition of this finite realization. This does not claim that Volume III's test is a universal admissibility axiom for every realization.

All objects used below belong to F:
S0={o1,o2}
S1={o1,o2,a}
S2={o1,o2,b}
SM={o1,o2,a,b}
SN={p,q,r}.

Their induced equivalence classes are:
C0: {o1}, {o2}
C1: {o1,a}, {o2}
C2: {o1,b}, {o2}
M:  {o1,a,b}, {o2}
N:  {p,r}, {q}.

Each object has at least two elements and an apartness witness, since each contains an element from K and an element from L.

============================================================
3. COMMON SPAN AND CANDIDATE AMALGAM
============================================================

Use the span:

C0 --f1--> C1
C0 --f2--> C2

where f1 and f2 are literal inclusions.

Define:
M = C_SM, where SM=S1 union S2={o1,o2,a,b}.

Define j1:C1 -> M and j2:C2 -> M as literal inclusions.

Because every object carries the restriction of one fixed ambient relation #:
- f1 and f2 are injective and preserve/reflect apartness;
- j1 and j2 are injective and preserve/reflect apartness;
- the square commutes:
  j1 o f1 = j2 o f2.

Thus M is a common amalgam in each of the two categories defined below.

============================================================
4. CATEGORY A: INCLUSION-ONLY CATEGORY P_F
============================================================

Objects:
All C_S for S in F.

Morphisms:
There is exactly one morphism C_S -> C_T when S subseteq T, namely the literal inclusion. There is no morphism otherwise.

Category verification:
- Identity: S subseteq S.
- Composition: if S subseteq T and T subseteq V, then S subseteq V.
- Associativity and identity laws follow from composition of inclusions.

Every inclusion is an embedding because all structures are restrictions of the same ambient relation #.

PUSHOUT CLAIM:
M is the pushout of the span C1 <- C0 -> C2 in P_F.

PROOF:
The inclusions j1:C1 -> M and j2:C2 -> M form a cocone and agree on C0.

Let C_T be any object of P_F and suppose a cocone is given:
u1:C1 -> C_T,
u2:C2 -> C_T.

By the definition of P_F, these arrows exist only as literal inclusions. Therefore:
S1 subseteq T
and
S2 subseteq T.

Hence:
SM=S1 union S2 subseteq T.

Since M=C_SM is an object of P_F, there is a unique inclusion:
h:M -> C_T.

By construction:
h o j1 = u1
and
h o j2 = u2.

Uniqueness follows because P_F has at most one arrow between any two objects.

Therefore M satisfies the pushout universal property in P_F.

RESULT A:
PUSHOUT IN P_F: PROVED for this explicit realization.

============================================================
5. CATEGORY B: ALL EMBEDDINGS E_F
============================================================

Objects:
Exactly the same objects C_S for S in F.

Morphisms:
All injective functions f:S -> T satisfying:
x #_S y iff f(x) #_T f(y).

Category verification:
- Identity maps satisfy injectivity and preserve/reflect apartness.
- The composite of two injective maps is injective.
- If f and g preserve and reflect apartness, then:
  x #_S y
  iff f(x) #_T f(y)
  iff g(f(x)) #_V g(f(y)).
Thus the composite is again an embedding.
- Associativity and identity laws are inherited from function composition.

The same span maps f1,f2 and cocone maps j1,j2 are morphisms in E_F.

COUNTER-COCONE:
Take the already defined object N=C_SN, with equivalence classes {p,r} and {q}.

Define:
g1:C1 -> N
g1(o1)=p
g1(o2)=q
g1(a)=r.

Define:
g2:C2 -> N
g2(o1)=p
g2(o2)=q
g2(b)=r.

Check g1:
- It is injective because p,q,r are distinct.
- o1 #1 a is false because o1 ~1 a; p #N r is false because p ~N r.
- o1 #1 o2 is true; p #N q is true.
- a #1 o2 is true; r #N q is true.
Therefore g1 preserves and reflects apartness.

Check g2:
- It is injective because p,q,r are distinct.
- o1 #2 b is false because o1 ~2 b; p #N r is false because p ~N r.
- o1 #2 o2 is true; p #N q is true.
- b #2 o2 is true; r #N q is true.
Therefore g2 preserves and reflects apartness.

Agreement on C0:
g1 o f1 = g2 o f2,
since both maps send o1 to p and o2 to q.

Thus (g1,g2) is a valid cocone in E_F.

FAILURE OF THE PUSHOUT PROPERTY:
If M were a pushout in E_F, there would exist a morphism h:M -> N satisfying:
h o j1 = g1
and
h o j2 = g2.

These equations force:
h(o1)=p
h(o2)=q
h(a)=r
h(b)=r.

But a and b are distinct elements of M, while h(a)=h(b).
Therefore h is not injective.

Hence h is not a morphism in E_F.

The required factorization does not exist. Therefore M is not a pushout in E_F.

RESULT B:
M IS AN AMALGAM BUT NOT A PUSHOUT IN E_F.

5.1 STRONGER RESULT: NO PUSHOUT EXISTS IN E_F FOR THIS SPAN

The preceding counterexample shows that the particular object M is not a pushout. In the present fixed-carrier test category E_F, a stronger conclusion can be proved: no pushout object for this span exists.

Assume, for contradiction, that a pushout object P in E_F exists, with embedding cocone maps:
j1:C1 -> P
j2:C2 -> P
satisfying j1 o f1 = j2 o f2.

There are exactly two cases for the two distinguished images j1(a) and j2(b).

CASE 1:
j1(a) = j2(b).

Use the object N' with carrier {p,q,r,s} and equivalence classes:
{p,r,s}, {q}.

Define:
g1':C1 -> N'
g1'(o1)=p
g1'(o2)=q
g1'(a)=r.

Define:
g2':C2 -> N'
g2'(o1)=p
g2'(o2)=q
g2'(b)=s.

Both maps are injective and preserve/reflect equivalence, hence preserve/reflect apartness. They agree on C0, so they form a cocone.

The pushout property would provide h':P -> N' with:
h' o j1 = g1'
h' o j2 = g2'.

But j1(a)=j2(b) would force:
r = h'(j1(a)) = h'(j2(b)) = s,
contrary to r and s being distinct.

Thus no factorization exists in Case 1.

CASE 2:
j1(a) != j2(b).

Use the previous object N with equivalence classes {p,r}, {q}, and the previous cocone g1,g2, where:
g1(a)=r
g2(b)=r.

The pushout property would provide h:P -> N satisfying:
h o j1 = g1
h o j2 = g2.

It follows that:
h(j1(a))=r=h(j2(b)).

Since j1(a) and j2(b) are distinct in Case 2, h is not injective. Therefore h is not a morphism in E_F.

Thus no factorization exists in Case 2 either.

Both cases are impossible. Therefore:

FORMAL RESULT:
The span C1 <- C0 -> C2 has NO PUSHOUT in E_F for this explicit fixed-carrier object family and embedding morphism class.

SCOPE:
This nonexistence result is specific to the declared finite carrier U0, object family F, and all-embeddings category E_F. It is not a theorem that every embedding category lacks pushouts, and it does not identify E_F with C_METACORE.
