2. SOURCE REALIZATION AND CATEGORY
============================================================

Choose the finite carrier:
U0={a,b,c,d}.

Use the standard finite apartness realization:
x # y iff x != y.

This relation satisfies:
IRREFLEXIVITY:
not(x # x).

SYMMETRY:
x # y iff y # x.

COTRANSITIVITY:
if x # y, then for every z either x # z or z # y.
For inequality on a set, if z=x then z!=y; if z!=x then x!=z.

This is the standard apartness realization described in Volume II, Section III.2.
Volume II explicitly treats it as one admissible realization, not the only possible realization.

Define APFin_nontriv_emb as the auxiliary category with:
- objects: finite sets of size at least 2 carrying standard inequality apartness;
- morphisms: injective maps preserving and reflecting apartness.

This auxiliary category is a test realization compatible with the stated finite nontriviality condition.
It is not asserted to be the complete canonical C_METACORE.

4. STRONG AMALGAM
============================================================

Define:
P={a,b,c,d}
with:
x #P y iff x != y.

Let:
j1:S1->P be the inclusion;
j2:S2->P be the inclusion.

Both are injective and preserve and reflect apartness.

Their images satisfy:
j1(S1) intersect j2(S2) = {a,b} = image(S0).

Thus the non-base elements c and d remain distinct.
P is a valid finite nontrivial apartness object.

Therefore P is a strong amalgam of this specific span in APFin_nontriv_emb.

This is an existence result for the selected span, not a proof that every span in the category has a strong amalgam.

============================================================
5. CATEGORICAL PUSHOUT TEST
============================================================

P is not a categorical pushout in APFin_nontriv_emb.

Take:
Q=S1={a,b,c}
with inequality apartness.

Let:
f1:S1->Q be the identity;
f2:S2->Q be:
f2(a)=a;
f2(b)=b;
f2(d)=c.

Both maps are embeddings because each source and target carries full inequality apartness and each map is injective.

They agree on S0.

If h:P->Q were a morphism satisfying:
h composed with j1 = f1
and
h composed with j2 = f2,
then:
h(a)=a;
h(b)=b;
h(c)=c;
h(d)=c.

Hence h(c)=h(d), so h is not injective.
Therefore h is not an embedding.

The cocone has no mediating morphism from P in the embedding category.
Thus P is not a categorical pushout.

The result is consistent:
P is a strong amalgam, but not a categorical pushout.

============================================================
6. STOCHASTIC AUTOMORPHISM ON THE CORRECTED P
============================================================

Define:
g(a)=a;
g(b)=b;
g(c)=d;
g(d)=c.

Then:
g(g(x))=x.

Since g is a permutation, it preserves and reflects inequality:
x #P y iff g(x) #P g(y).

Thus g is an automorphism of the corrected P.

For p in [0,1], define:
kappa(x,.)=(1-p)delta_x+p delta_g(x).

For n-tuples:
Lambda_n(x1,...,xn;.)
=(1-p)delta_(x1,...,xn)
+p delta_(g(x1),...,g(xn)).

Properties:
- each coordinate marginal is kappa(x_i,.);
- projective consistency holds;
- permutation equivariance holds;
- any coordinatewise inequality constraint is preserved because the same injective map g acts on every coordinate;
- the kernel is measurable on the finite discrete space.

This proves relational stochastic preservation for this particular finite nontrivial realization.
