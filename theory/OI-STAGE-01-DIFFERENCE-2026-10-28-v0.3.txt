1. AIM
Give “Difference” an explicit, minimal mathematical meaning. Do not assume that a difference by itself produces a direction, a law, dynamics, persistence, or organization.

2. DEFINITION: SIGNATURE-BASED DIFFERENCE
Let X be a nonempty set of states or objects. Let I be a set of features, and for each i∈I let V_i be a feature-value set and f_i:X→V_i a feature map. Define the observed difference predicate D:X×X→{0,1} by:
D(x,y)=1 iff there exists i∈I such that f_i(x)≠f_i(y).
Otherwise D(x,y)=0.
The feature family is part of the model. Difference is therefore relative to a declared signature, not an unqualified metaphysical primitive.

CLASSICAL FRAMEWORK AND SIGNATURE MAP
Work in classical logic and ZF set theory, without the Axiom of Choice. Every f_i is total by definition. Define F:X→∏_{i∈I}V_i by F(x)=(f_i(x))_{i∈I}.

LEMMA 2.1 — COORDINATE/SIGNATURE EQUIVALENCE
For all x,y∈X:
F(x)=F(y) iff for every i∈I, f_i(x)=f_i(y).
Consequently:
D(x,y)=1 iff there exists i∈I with f_i(x)≠f_i(y) iff F(x)≠F(y).
Proof: equality in a Cartesian product is extensional, hence equality of product elements is equivalent to equality at every coordinate. Its negation is equivalent, in classical logic, to existence of a coordinate at which equality fails. QED.

DEGENERATE INDEX-SET CASE
If I=∅, the indexed product is the singleton containing the empty function. Since X is nonempty, F is constant and D(x,y)=0 for all x,y∈X. The quotient by D-indistinguishability then has exactly one class. This is a valid degenerate case, not a contradiction to the general construction.

3. IMMEDIATE PROPERTIES
P1 (irreflexivity): D(x,x)=0 for every x∈X, because f_i(x)=f_i(x) for every feature i.

P2 (symmetry): D(x,y)=D(y,x), because inequality of feature values is symmetric.

P3 (non-identity limitation): D(x,y)=0 does not necessarily imply x=y. It implies only that the selected feature family fails to distinguish x and y. If the combined signature map F(x)=(f_i(x))_{i∈I} is injective, then D(x,y)=0 iff x=y.

P4 (signature dependence): adding or removing features can change D. Therefore a claim that two states differ must specify which features are admitted.

P5 (cotransitivity): If D(x,y)=1, then for every z∈X, D(x,z)=1 or D(z,y)=1. Proof: choose i∈I with f_i(x)≠f_i(y). If f_i(x)≠f_i(z), then D(x,z)=1. Otherwise f_i(x)=f_i(z), so f_i(z)≠f_i(y), and D(z,y)=1. Thus the predicate induced by a feature family is cotransitive.

This property is a theorem about this signature-based definition. It does not establish that the definition is the unique or canonical interpretation of Difference in OMEGA-ISOP.

4. FINITE TEST
Take X={a,b,c}, with one feature f:X→{0,1} defined by f(a)=0, f(b)=1, f(c)=0.
Then D(a,b)=1, D(b,c)=1, and D(a,c)=0.
This confirms that D need not be transitive. It also shows that two distinct objects may be indistinguishable under the chosen feature family. The example is consistent with cotransitivity: for D(a,b)=1 and z=c, D(a,c)=0 but D(c,b)=1.

5. NON-DERIVATION TEST: DIFFERENCE DOES NOT DETERMINE A UNIQUE RELATION

Let:
P_D = {(x,y)∈X×X : D(x,y)=1}.

DEFINITION
A binary relation R on X is called D-compatible if and only if:
R⊆P_D.

Thus a D-compatible relation contains only ordered pairs that are positive under D. This definition does not impose reflexivity, symmetry, transitivity, or any orientation rule on R.

FINITE EXAMPLE
For the example in Section 4:
R₁={(a,b)}
R₂={(a,b),(b,c)}.
Since D(a,b)=1 and D(b,c)=1, both R₁ and R₂ are D-compatible. They are distinct, so D does not select a unique D-compatible directed relation in this example.

GENERAL BOUNDARY
If P_D is nonempty, then at least two distinct D-compatible relations exist: the empty relation ∅ and any singleton {(x,y)} with (x,y)∈P_D.
If P_D is empty (equivalently, D≡0), the only D-compatible relation under this definition is ∅. Therefore non-uniqueness is conditional on the existence of at least one D-positive ordered pair.

Moreover, D is symmetric and does not select an orientation. Any directional interpretation requires additional structure or an explicit orientation rule.
This result concerns the stated definition of D-compatibility only. It does not rule out deriving a relation from richer data or additional axioms.

6. THEOREM
The signature-based difference predicate D is irreflexive, symmetric, and cotransitive. It is not necessarily transitive. Whenever at least one D-positive ordered pair exists, D admits at least two distinct D-compatible relations under the definition in Section 5. In the degenerate case D≡0, that definition admits only the empty relation.

PROOF
Irreflexivity and symmetry follow directly from the definition in Section 2. Cotransitivity follows from the witness-feature argument in P5. Non-transitivity is witnessed by the finite test: D(a,b)=1 and D(b,c)=1 but D(a,c)=0. Non-uniqueness in the finite test is witnessed by R₁ and R₂ in Section 5; the general conditional statement follows from the empty relation and a singleton positive pair. If no positive pair exists, P_D=∅ and the only D-compatible relation is ∅. QED.

7. WHAT THIS DOES AND DOES NOT ESTABLISH
Established mathematically: the stated properties of D, including cotransitivity, and the finite non-uniqueness counterexample.
Model-dependent: which features I and maps f_i are appropriate for a given OMEGA-ISOP application.
Not established: that the existing Frozen Core uniquely entails this exact definition; that every difference produces a uniquely selected relation; that direction, constraint, dynamics, persistence, or organization follows from difference alone.
The signature-based D has properties often associated with an apartness-style relation, but no claim is made here that it satisfies every possible formal definition of apartness used elsewhere in the project.

LOGICAL SCOPE: The cotransitivity proof in Section 3 uses classical logic, specifically the classical split between equality and inequality at the selected coordinate. No constructive cotransitivity theorem is claimed.
The arrow “Difference → Relation” is therefore not accepted as an unconditional theorem. It remains a conditional construction problem for Stage 2.
