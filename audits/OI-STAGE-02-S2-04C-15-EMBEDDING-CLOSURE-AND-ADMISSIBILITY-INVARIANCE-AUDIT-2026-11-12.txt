2. SOURCE DEFINITIONS
============================================================

2.1 LOCAL CONFIGURATIONS

Volume II represents a local configuration as:

C = (S_C,#_C)

where:

S_C subseteq U0

and:

#_C = # restricted to S_C x S_C.

The exact admissibility conditions are stated to be realization-dependent.

2.2 SOURCE-DEFINED EMBEDDING CONDITION

For configurations:

C1 = (S1,#1)
C2 = (S2,#2)

an embedding f:C1 -> C2 is injective and preserves and reflects apartness:

for all x,y in S1:

x #1 y iff f(x) #2 f(y).

The biconditional is essential. Preservation alone is insufficient.

2.3 MINIMAL NONTRIVIALITY

Volume II states the cardinality condition:

|S_C| >= 2.

Volume III, Section 6, specifies a nontriviality test that also requires an actual apartness witness:

there exist x,y in S_C such that x #_C y.

These conditions are treated here as the stated minimal nontriviality test. They are not promoted to a complete universal admissibility predicate for every realization.

============================================================
3. FORMAL RESULT A — IDENTITY AND COMPOSITION
============================================================

Let C1=(S1,#1), C2=(S2,#2), and C3=(S3,#3) be configurations.

Let:

f:C1 -> C2
g:C2 -> C3

be source-defined apartness embeddings.

By definition:

(1) f is injective.
(2) g is injective.
(3) For all x,y in S1:
    x #1 y iff f(x) #2 f(y).
(4) For all u,v in S2:
    u #2 v iff g(u) #3 g(v).

3.1 INJECTIVITY OF THE COMPOSITE

Suppose:

(g o f)(x) = (g o f)(y).

Then:

g(f(x)) = g(f(y)).

Since g is injective:

f(x) = f(y).

Since f is injective:

x = y.

Therefore g o f is injective.

3.2 PRESERVATION AND REFLECTION OF APARTNESS

For all x,y in S1:

x #1 y
iff f(x) #2 f(y)
iff g(f(x)) #3 g(f(y)).

Therefore:

x #1 y iff (g o f)(x) #3 (g o f)(y).

Thus g o f preserves and reflects apartness.

3.3 IDENTITY

For every configuration C=(S,#), the identity map:

id_S:S -> S

is injective and satisfies:

x # y iff id_S(x) # id_S(y).

Therefore id_C is a source-defined embedding.

3.4 CONCLUSION

The class of all injective maps preserving and reflecting the selected apartness relation is closed under identities and composition.

Function composition is associative. Consequently, if a fixed class O of admissible configurations is specified as the objects, and the morphisms are defined to be all such embeddings between objects of O, those objects and morphisms form a category.

FORMAL RESULT A:
IDENTITIES: CLOSED.
COMPOSITION: CLOSED.
ASSOCIATIVITY: INHERITED FROM FUNCTION COMPOSITION.
CATEGORY AXIOMS FOR THE ALL-APARTNESS-EMBEDDINGS CLASS: SATISFIED ON ANY FIXED OBJECT CLASS O.

IMPORTANT LIMIT:
This result proves category closure after the object class has been specified. It does not identify the correct project object class O, nor prove that every source-defined embedding is intended to be a C_METACORE morphism.

============================================================
4. FORMAL RESULT B — INVARIANCE OF MINIMAL NONTRIVIALITY
============================================================

Let C=(S,#) satisfy:

|S| >= 2

and:

there exist x,y in S such that x # y.

Let:

f:C -> D=(T,#_D)

be a source-defined apartness embedding.

4.1 CARDINALITY

Since f is injective and S contains at least two distinct elements, f(S) contains at least two distinct elements.

Therefore:

|f(S)| >= 2.

This conclusion applies to finite and infinite S; injectivity preserves the cardinality of the image.

4.2 APARTNESS WITNESS

Choose x,y in S with x # y.

By preservation of apartness:

f(x) #_D f(y).

Since f is injective and x != y:

f(x) != f(y).

Thus the image f(S), equipped with the induced relation from D, contains an apartness witness.

4.3 REFLECTION

The biconditional also prevents a false apartness distinction from being introduced or removed between points in the image:

x # y iff f(x) #_D f(y).

Therefore the induced relational pattern on f(S) is isomorphic to the source configuration.

FORMAL RESULT B:
THE MINIMAL NONTRIVIALITY TEST
(|S| >= 2 AND EXISTS x,y IN S WITH x # y)
IS PRESERVED BY EVERY SOURCE-DEFINED APARTNESS EMBEDDING.

SCOPE:
This proves invariance of the stated minimal nontriviality test. It does not prove invariance of every possible realization-dependent admissibility condition.

============================================================
5. ADMISSIBILITY INVARIANCE — EXACT BOUNDARY
============================================================

5.1 WHAT FOLLOWS

The following properties follow from the source embedding definition:

- Injectivity preserves the number of distinct elements in the image.
- Preservation carries an existing apartness witness into the image.
- Reflection ensures that the apartness pattern on the image agrees with the source pattern.
- The source configuration and its image are isomorphic as structures whose only selected relation is apartness.

5.2 WHAT DOES NOT FOLLOW

The source does not provide a complete predicate:

Adm(C)

for all admissible configurations.

It expressly leaves exact admissibility realization-dependent.

Therefore the following implications are not established:

Adm(C) AND f is an apartness embedding
DOES NOT, FROM THE AVAILABLE SOURCE TEXT ALONE, PROVE
Adm(f(C)).

Likewise, the available source text does not prove that every additional realization-specific property is preserved by every apartness embedding.

5.3 WHY THIS GAP IS MATHEMATICALLY REAL

An admissibility rule may depend on structure not encoded by apartness alone, for example:
- distinguished elements or constants;
- additional relations or operations;
- ambient-carrier restrictions;
- boundary or realization data;
- external compatibility conditions.

An apartness embedding need not preserve such data unless that data is included in the structure and the morphism definition explicitly preserves it.

This is an explanatory list of possible additional structures, not a claim that the project sources currently impose any one of them.

5.4 IMAGE CLOSURE VERSUS CATEGORY CLOSURE

These are different claims.

CATEGORY CLOSURE:
If O is already a specified class of objects and all apartness embeddings between objects of O are taken as morphisms, identities and composition are closed by Formal Result A.

IMAGE / SUBOBJECT ADMISSIBILITY:
The stronger claim that the image f(S) is itself an admissible object, or that every induced subconfiguration of an admissible object is admissible, requires an additional closure or invariance condition on Adm.

The first claim does not imply the second.

5.5 UNION CLOSURE

The minimal test predicate in S2-04C-12 is preserved under nonempty unions of its objects because any one member contributes at least two elements and an apartness witness that remain in the union.

That argument does not extend automatically to an unspecified stronger predicate Adm_real(C).

For a stronger admissibility predicate, union closure must be proved from its exact definition. It cannot be inferred from the minimal nontriviality test.

AUDIT FINDING:
The source embedding formula is sufficient for identity/composition closure and for preservation of minimal nontriviality. It is insufficient, without further hypotheses, to establish invariance of the complete realization-dependent admissibility predicate.

============================================================
6. RESTRICTED MORPHISM CLASSES — PREDICATE CLOSURE
============================================================

Suppose a proposed restricted morphism class is defined by:

Hom_P(C,D) =
{ f:C -> D : f is an apartness embedding AND P(f) }.

For this to define a category on the chosen objects, at minimum:

P1. Identity condition:
For every object C, P(id_C) must hold.

P2. Composition condition:
For all composable f:C -> D and g:D -> E,
P(f) AND P(g) must imply P(g o f).

P3. Typed hom condition:
P(f) must be a well-defined predicate for maps between the declared objects.

The apartness-embedding part is already closed under identities and composition by Formal Result A.

The additional predicate P is not source-specified. Its identity and composition closure cannot be verified until P is explicitly defined.

A restriction based on global automorphism extension, named-carrier preservation, distinguished constants, or other additional structure would require its own exact definition and closure proof.

No such restriction is adopted by this audit.

FORMAL REQUIREMENT:
A proposed M3-style restricted subclass must state P(f) explicitly and prove P1-P3. The phrase "preserves selected structural properties" is not by itself an executable hom-set definition.

============================================================
7. FIXED AMBIENT CARRIER — LOCAL MAPS AND GLOBAL EXTENSIONS
============================================================

The source represents configurations as subsets of U0.

A local embedding:

f:S -> T

between two such configurations is a map between the local carriers.

The definition does not require f to extend to a global automorphism:

g:(U0,#) -> (U0,#).

These are different mathematical properties.

A local apartness embedding may be valid as a map between the selected configurations even when no ambient automorphism extension has been established.

Conversely, the absence of a source-level extension requirement does not prove that a project-specific realization could never impose one.

RESULT:
Global automorphism extension is not needed for Formal Result A.
Global automorphism extension remains an additional, source-unestablished restriction for C_METACORE.
