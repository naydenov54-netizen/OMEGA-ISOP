14. THEOREM 91 — OPERATIONAL RESPONSE NON-EXPANSION: PROOF AUDIT

AUTHORITATIVE MATHEMATICAL SOURCE:
Volume II v1.3-MF-AUDIT-RESTORED-FINAL, Section VIII.5.
CONTROLLED HANDOFF:
M3.2 v1.5, Section 9.
RELATED DEFINITIONS:
Volume II Section VIII.3; Volume III Sections 18-20.

STATEMENT:
D_L(T(M1),T(M2)) <= D_L(M1,M2).

PROOF CHECK:
For a common map tau:L_op -> L_op and every a in L_op:
||Resp_(T(M1))(a)-Resp_(T(M2))(a)||
= ||Resp_M1(tau(a))-Resp_M2(tau(a))||
<= sup_{b in L_op} ||Resp_M1(b)-Resp_M2(b)||
= D_L(M1,M2).
Taking the supremum over a gives the stated inequality.
The proof is mathematically valid under the uniform compatibility and domain conditions below.

REQUIRED QUANTIFIER / DOMAIN CONDITIONS:
1. One and the same tau must work for every M in the comparison class C, not a different tau_M for each model.
2. tau(a) must lie in the same L_op over which the original D_L is defined.
3. Responses for M, T(M), and all relevant probes must be defined in the common response space Y.
4. T must map the selected comparison class into the domain on which the transformed distance is evaluated. A sufficient explicit condition is T(C) subseteq C.
5. The operational criterion, response space and comparison class must remain fixed.
6. L_op must be nonempty for the stated extended-pseudometric interpretation; Y must be normed.

QUANTIFIER CHECK:
The Volume II proof applies the same tau to both M1 and M2. The theorem's singular "there exists a map tau" must therefore be read uniformly over the comparison class. If tau is allowed to depend on M, the displayed proof does not follow.

FINITE COUNTEREXAMPLE TO MODEL-DEPENDENT tau:
Let L_op={a,b}, Y=R.
Let Resp_M1(a)=0, Resp_M1(b)=10.
Let Resp_M2(a)=0, Resp_M2(b)=10.
Then D_L(M1,M2)=0.
If tau_M1 is the constant map to a and tau_M2 is the constant map to b, define transformed responses by the model-specific covariance identities. Then Resp_T(M1)(a)=0 and Resp_T(M2)(a)=10, so the transformed distance is at least 10.
Therefore a model-dependent tau cannot replace the common tau assumption.

SURJECTIVE-tau COROLLARY:
If the common tau is surjective, then:
D_L(T(M1),T(M2)) = D_L(M1,M2).
Reason: the supremum over tau(L_op) equals the supremum over all L_op.
Surjectivity is not needed for non-expansion; it is sufficient for exact distance preservation.
If tau is not surjective, strict contraction may occur.

H1 / H4 INTERPRETATION:
The algebraic inequality itself uses the response covariance, norm and common probe domain. R-existence, admissibility and preservation supply the structural context for T. The comparison-class condition must also ensure the transformed models remain in the relevant response domain. These semantic conditions must not be silently omitted when applying the theorem to a concrete realization.

PHYSICAL BRIDGE STATUS:
Theorem 91 is a conditional mathematical statement about a response-distance under a probe-covariant transformation. It does not by itself establish physical information conservation, entropy conservation, unitarity, or a physical law. A physical application requires a concrete model, observables/probes, response map, transformation T, and a verified common tau.

AUDIT RESULT:
PROOF: PASS UNDER THE EXPLICIT UNIFORM-tau AND DOMAIN CONDITIONS.
THEOREM STATUS: CONDITIONAL THEOREM, UNCHANGED.
NEW COROLLARY: SURJECTIVE tau IMPLIES DISTANCE PRESERVATION, NOT MERELY NON-EXPANSION.
NO CANONICAL THEOREM EDIT.
NO PHYSICAL CLAIM.
NO RL / CE REGISTRATION.

16. CE-V-04 — DYNAMIC STATE SUFFICIENCY: FORMAL PROOF AUDIT

SOURCE:
CE-V retained extensions archive, CE-V-04 entry.
Related formal setting: Volume II v1.3, reduction/coarse-graining and dynamical sections.
Related validation framework: Volume III v1.1, deterministic/stochastic dynamics and operational validation.

FORMAL SETTING:
X is the full state space.
xi:X -> Z is a selected reduced representation.
Define x ~_xi y iff xi(x)=xi(y).
For deterministic T:X->X, the closure condition is:
xi(x)=xi(y) => xi(T(x))=xi(T(y)).

MATHEMATICAL INTERPRETATION:
The condition is exactly the requirement that T descend to a well-defined map T_bar on the image xi(X), satisfying:
xi(T(x)) = T_bar(xi(x)).
Proof of sufficiency: define T_bar(z)=xi(T(x)) for any x with xi(x)=z. The closure condition guarantees that the value is independent of the representative x. Necessity follows immediately if such a T_bar exists.
This is the standard quotient/factor-map condition for deterministic dynamics. It is not a new universal physical theorem.

FINITE VALIDATION MODEL:
X={(0,0),(0,1),(1,0),(1,1)}
T(s,z)=(s xor z,z)
xi_full(s,z)=(s,z)
xi_red(s,z)=s.

Full representation:
xi_full is injective, so equality of reduced labels implies equality of full states. Closure holds.

Reduced representation:
(0,0) ~_xi_red (0,1), because both map to 0.

27.4 PROPOSED PILOT SCOPE — ONE-DIMENSIONAL CLASSICAL HARMONIC OSCILLATOR

Status: PROPOSED CANDIDATE ONLY; not yet a selected or completed physical pilot.

Reference physical model:
State space X = R^2 with x=(q,p).
Parameters m>0 and omega>0.
Dynamics:
dq/dt = p/m
dp/dt = -m*omega^2*q

Exact time-t map:
T_t(q,p) = (q*cos(omega*t) + p/(m*omega)*sin(omega*t),
            p*cos(omega*t) - m*omega*q*sin(omega*t))

Reduced representation:
xi(q,p) = q.

Closure test:
Take two states (q,p1) and (q,p2) with p1 != p2.
They have the same reduced state:
xi(q,p1) = xi(q,p2) = q.

Their reduced states after time t differ by:
xi(T_t(q,p1)) - xi(T_t(q,p2))
= (p1-p2)/(m*omega)*sin(omega*t).

For generic t with sin(omega*t) != 0, this difference is nonzero. Therefore the position-only representation is not closed under the first-order state evolution. The full state (q,p) is closed.

Critical qualification:
This does NOT mean the oscillator cannot be described using q. The familiar second-order equation
d^2q/dt^2 + omega^2*q = 0
is valid, but it uses q and its time derivative/initial velocity as dynamical information. The pilot tests sufficiency of q ALONE as a first-order state representation, not the validity of the oscillator model.

Physical interpretation:
q is position; p is momentum; xi discards momentum. The omitted momentum affects the future position. This is an explicit coarse-graining/state-sufficiency test.

Proposed checks:
1. Verify the exact flow map and its domain.
2. Verify closure for the full representation xi_full(q,p)=(q,p).
3. Construct explicit same-q/different-p counterexamples for the reduced representation.
4. Identify exceptional times where sin(omega*t)=0 and explain why a single-time coincidence does not establish closure for all t.
5. Compare the first-order reduced-state requirement with the equivalent second-order q equation.
6. State clearly that omitted momentum is a standard dynamical variable, not a newly discovered hidden entity or fundamental memory.
7. Keep all physical parameters and assumptions explicit; do not claim an empirical result from the analytic model alone.

Classification at proposal stage:
M1: CE-V-04 deterministic closure criterion.
M2: exact difference formula above, conditional on the standard oscillator flow.
P1: position-only coarse-graining correspondence.
P3: NOT YET ASSIGNED as an OMEGA-derived physical model; the oscillator is a known reference system used to test the criterion.
C1: NOT YET GENERATED; no new simulation has been run.
E1: NOT PRESENT; no experiment or observation is claimed.
O1: stochastic extension is not part of this deterministic pilot.
