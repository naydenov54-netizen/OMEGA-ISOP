3. RATIONAL TAYLOR ENCLOSURE
----------------------------------------------------------------

Let

S = SUM(k=0..100) x^k/k!

and

a_101 = x^101/101!

For k >= 101, the ratio of consecutive positive Taylor terms is

(x^(k+1)/(k+1)!) / (x^k/k!) = x/(k+1).

For all k >= 101 this ratio is at most

q = x/102.

Since x = 4225/129, we have 0 < q < 1.

Therefore the positive Taylor tail is bounded by a geometric
series:

0 < exp(x) - S <= a_101/(1-q).

Define

R = a_101/(1-q).

S < exp(x) <= S + R.

All quantities S, R and q are rational and can be evaluated
exactly using rational arithmetic.

Taking reciprocals of positive quantities gives

1/(S+R) <= exp(-x) < 1/S.

U_upper = 1/S
