4. DETERMINISTIC REALIZATION-LEVEL BRIDGE
==================================================
Consider a particular class of deterministic operational models with state x_M in X, admissible interventions A_a : X → X, and readout q : X → Y.

Define:
Resp_M(a) = q(A_a(x_M))
j(a) = q ∘ A_a
j(a)(x) = q(A_a(x))

Assume j(a) belongs to a common observable space B and define the transformed model state by x_(T(M))=T(x_M).
The Koopman operator is:
K_T f = f ∘ T

If the intervention class is closed under precomposition by T, in the specified protocol order, then for every a there exists τ(a) such that:
A_(τ(a)) = A_a ∘ T

Consequently:
j(τ(a)) = K_T(j(a))
Resp_(T(M))(a)
= q(A_a(T(x_M)))
= q(A_(τ(a))(x_M))
= Resp_M(τ(a))

If j is injective, τ = j^(-1) ∘ K_T ∘ j. If j is not injective, the action must instead be well-defined on the quotient A/~ where a1~a2 iff j(a1)=j(a2).

This proves H3 only for this particular realization class under the stated assumptions. It does not prove that these assumptions are supplied by the Frozen Core.

Important protocol-order limitation: the construction represents the sequence state → T → intervention A_a → readout q. It cannot be silently reused for state → intervention → T → readout; the operator composition changes.

5. STOCHASTIC MARKOV-KOOPMAN REALIZATION-LEVEL BRIDGE
==================================================
Consider a Markov model with state space X, initial probability measure μ_M, Markov kernel κ, intervention A_a : X → X, and readout q : X → Y.

Define:
j(a)=q∘A_a
Resp_M(a)=∫j(a)(x)dμ_M(x)

Define the Markov-Koopman operator:
K_κ f(x)=∫f(y)κ(x,dy)

Define the evolved measure:
μ'_M(E)=∫κ(x,E)dμ_M(x)
μ'_M=μ_M κ

Then:
Resp_(κ(M))(a)
=∫j(a)(y)dμ'_M(y)
=∫[∫j(a)(y)κ(x,dy)]dμ_M(x)
=∫K_κ(j(a))(x)dμ_M(x)

If the observable representation is common and the closure condition holds:
K_κ(j(a))=j(τ(a)) for every a in L_op,
then:
Resp_(κ(M))(a)=Resp_M(τ(a)).

Thus H3 is conditionally derived for this Markov realization class. If j is injective, τ=j^(-1)∘K_κ∘j. Otherwise the induced action must be well-defined on the quotient by equality of represented observables.

Required conditions (SK1–SK7):
SK1: A common state space X.
SK2: A common observable space B.
SK3: Each operational probe has a representation j(a) in B.
SK4: Response factors through integration of j(a) against μ_M.
SK5: A common Markov kernel κ acts on the entire comparison class, or the induced action is otherwise shown to be common.
SK6: K_κ(j(L_op)) is contained in j(L_op), or the corresponding quotient image is invariant.
SK7: The functions are measurable/integrable and the required integrals exist.

Deterministic consistency check:
κ_T(x,E)=1_E(T(x)) gives K_(κ_T)f(x)=f(T(x))=K_T f(x).
The deterministic bridge is therefore a special case of the Markov construction.

Non-Markov limitation:
If future evolution depends on history beyond the current state, a Markov kernel on the original X is insufficient. A history-augmented state space may restore a Markov description only if it contains sufficient predictive information and the required measurable structure exists. This is an additional construction, not automatic.

6. CONDITIONAL CONSEQUENCE FOR OPERATIONAL DISTANCE
==================================================
If a common τ : L_op → L_op satisfies H3 for all models in the comparison class, then:
D_L(κ(M1),κ(M2))
= sup_(a∈L_op)||Resp_M1(τ(a))-Resp_M2(τ(a))||_Y
≤ D_L(M1,M2).

This is non-expansion, not necessarily equality. Equality requires additional properties, for example suitable surjectivity/invertibility of τ over the operational language.

9. LIMITATIONS AND NON-IMPLICATIONS
==================================================
- The bridge is realization-level and conditional, not a new Frozen Core primitive.
- The closure condition is substantive and cannot be inserted merely to force H3.
- Model-dependent kernels may induce model-dependent τ_M; this does not satisfy H3 unless a common action is proved over the comparison class.
- If the intervention itself is stochastic, it should be represented by an appropriate kernel/policy and composition order must be made explicit.
- If response depends on hidden variables, memory, path histories, or correlations omitted from X, the chosen state representation may be insufficient.
- H3 implies the stated non-expansion inequality, not metric preservation or equality.
