1. OBJECTIVE
==================================================
Test whether Markov-Koopman closure K_kappa(j(L_op)) subset j(L_op) follows naturally for independently specified operational probe classes, rather than being postulated to force H3.

Target proposition C:
For a fixed Markov kernel kappa and an independently specified operational probe class L_op represented by j in a common observable space B, does K_kappa(j(L_op)) subset j(L_op) follow from the Markov structure alone?

Answer established by the test:
NO, not for an arbitrary restricted operational probe class. YES for the maximal class of all bounded measurable scalar observables, under the usual measurable-kernel assumptions. Therefore closure is not a generic consequence for restricted operational languages; it depends on the independently chosen semantics and breadth of the probe class.

3. LOOP AUDIT L1-L8

L1 - TARGET:
C is the closure statement K_kappa(j(L_op)) subset j(L_op), quantified over every probe a in the chosen L_op, for the specified common kernel and representation.

L2 - DEPENDENCY CHAIN:
The Markov kernel induces K_kappa on bounded measurable functions by conditional expectation. Whether K_kappa maps the represented probe class back into itself depends on the definition of that class. The Markov property alone only guarantees preservation of the ambient bounded-measurable function space, not arbitrary subsets of it.

L3 - CONCLUSION SMUGGLING:
The positive result below chooses L_op to be all bounded measurable functions before examining closure. It does not define L_op as the invariant subspace generated by K_kappa and does not assume the target closure clause. Closure follows from the standard mapping property of a Markov kernel on bounded measurable functions.
The negative result fixes threshold indicators independently of K_kappa and shows that their class is not invariant under a non-degenerate Gaussian transition.

L4 - INDEPENDENCE:
The threshold class is specified by a measurement semantics (binary threshold detector) independent of the transition kernel. The Gaussian kernel is specified independently as additive measurement/state noise. The failure of closure is not imported into either definition.

4. POSITIVE CASE: MAXIMAL BOUNDED-MEASURABLE PROBE CLASS
==================================================
Let (X, Sigma) be a measurable space and kappa a Markov kernel on it.
Let B_b(X) be the vector space of all bounded, real-valued, Sigma-measurable functions on X.
Set L_op = B_b(X), with j the identity representation:
j(a) = a.
For a probability measure mu, define:
Resp_mu(a) = integral_X a(x) dmu(x).
Define the evolved measure mu' = mu kappa and:
K_kappa a(x) = integral_X a(y) kappa(x,dy).

For every a in B_b(X):
1. K_kappa a is measurable by the Markov-kernel measurability property.
2. |K_kappa a(x)| <= ||a||_infinity because kappa(x,.) is a probability measure.
3. Therefore K_kappa a is bounded and belongs to B_b(X).

Hence:
K_kappa(B_b(X)) subset B_b(X).

Set tau = K_kappa as a map from L_op to L_op. Then:
Resp_(mu kappa)(a)
= integral_X a(y) d(mu kappa)(y)
= integral_X K_kappa a(x) dmu(x)
= Resp_mu(tau(a)).

Thus H3 holds for this realization class, with a common tau whenever the same kernel kappa acts across the entire comparison class.

Important scope:
This is a broad, maximal observable language. It does not show that an actual physical or OMEGA-ISOP operational language contains every bounded measurable function. If different models use different kernels kappa_M, then tau_M=K_(kappa_M) may depend on M and a common H3 map still requires a separate proof.

5. NEGATIVE CASE: THRESHOLD-DETECTOR PROBE CLASS
==================================================
Let X=R with its Borel sigma-algebra. Fix sigma>0 and the additive Gaussian Markov kernel:
kappa(x,dy) = Normal(x, sigma^2)(dy).
Equivalently, X_next = x + epsilon, where epsilon is Normal(0,sigma^2).

Choose the operational probe class independently as binary threshold detectors:
L_thr = {a_c : c in R},
a_c(x) = 1_{[c,infinity)}(x).
Let B=B_b(R), j(a_c)=a_c, and define:
Resp_mu(a_c) = integral_R 1_{[c,infinity)}(x) dmu(x) = mu([c,infinity)).

The Markov-Koopman action is:
K_kappa(j(a_c))(x)
= integral_R 1_{[c,infinity)}(y) kappa(x,dy)
= P(x+epsilon >= c)
= Phi((x-c)/sigma),
where Phi is the standard normal cumulative distribution function.

For sigma>0, x -> Phi((x-c)/sigma) is continuous and strictly increasing, taking values strictly between 0 and 1 for every finite x. It is therefore not equal to any binary threshold indicator a_d, which takes only values 0 and 1 and has a jump discontinuity.
Thus:
K_kappa(j(L_thr)) is NOT a subset of j(L_thr).

Stronger failure of common H3:
Suppose there were a single map tau:L_thr -> L_thr such that for every initial probability measure mu and every c:
Resp_(mu kappa)(a_c) = Resp_mu(tau(a_c)).
Write tau(a_c)=a_d for some d. The equality for every mu would require:
integral Phi((x-c)/sigma) dmu(x) = integral 1_[d,infinity)(x) dmu(x)
for every probability measure mu.
Taking mu=delta_x for arbitrary x would force:
Phi((x-c)/sigma) = 1_[d,infinity)(x) for every x,
which is impossible.
Therefore no common tau into the threshold-detector class represents the Gaussian Markov transition for the full class of initial measures.

This is a concrete counterexample to the implication:
"Markov dynamics alone => closure of any independently chosen operational probe class."
It is not a counterexample to H3 under additional closure assumptions, and not a physical counterexample to OMEGA-ISOP.

6. COMPARATIVE RESULT
==================================================
Case A: L_op = B_b(X), j=id.
- Closure: YES.
- tau: K_kappa.
- H3: YES for response defined by expectation and a common kernel across the comparison class.
- Evidence: direct mathematical derivation.

Case B: L_op = threshold indicators on R, Gaussian additive-noise kernel.
- Closure: NO.
- Common tau across all initial measures: NO.
- H3: NOT REPRESENTABLE within the chosen threshold-only language.
- Evidence: explicit analytical counterexample.

Conclusion:
Closure is not a generic consequence of being Markov. It is a property of the pair (dynamics, operational language). A sufficiently rich probe language can be invariant, while a restricted and independently meaningful probe language can fail invariance.

7. IMPLICATION FOR M3.2 / H3
==================================================
The unresolved issue is now sharpened:
The question is not merely whether a Markov kernel has a Koopman operator. It does.
The question is whether the independently justified operational language of the relevant model class is invariant under that operator, and whether the same induced action applies across the full comparison class.

The current primary definitions do not identify L_op with B_b(X), do not define a representation j:L_op -> B, and do not select a threshold or other concrete operational semantics. Therefore neither the positive maximal-class case nor the negative threshold case can be promoted to a statement about all OMEGA-ISOP realizations.

The correct result is a domain-sensitive boundary theorem/criterion at realization level, not a universal OMEGA-ISOP theorem:
- If L_op is represented by a K_kappa-invariant function class and response factors through expectation, H3 follows for a common kernel.
- If the chosen represented probe class is not K_kappa-invariant, H3 need not follow; the Gaussian threshold example proves this.

No theorem number is assigned.
