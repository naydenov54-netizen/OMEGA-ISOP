==================================================
1. SETUP
==================================================

Let p=(p_1,...,p_d) be sorted nonincreasingly:
p_1>=...>=p_d>=0,
sum_i p_i=1.

Let r=min(d_A,d_B), and define:
P_k=sum_{i=1}^k p_i,
P_r=sum_{i=1}^r p_i,
t=1-P_r.

The rank-r spectral feasible set is:
F_r(p,eta)={
q_i>=0,
sum_i q_i=1,
q_{r+1}=...=q_d=0,
(1/2)sum_i|p_i-q_i|<=eta
}.

It is nonempty iff eta>=t.

For q supported on the first r coordinates:
D(p,q)=t+sum_{i=1}^r(p_i-q_i)_+.
Set epsilon=eta-t.

The MAX problem is:
maximize sum_{i=1}^r q_i^2
subject to:
q_i>=0,
sum_{i=1}^r q_i=1,
sum_{i=1}^r(p_i-q_i)_+<=epsilon.

==================================================
2. EXACT MAXIMIZER
==================================================

CASE 1: eta>=1-p_1.

The pure spectrum is feasible:
q*=(1,0,...,0).
It has purity 1, which is the largest possible value for any probability vector. Therefore it is a global maximizer.

CASE 2: t<=eta<1-p_1.

Set epsilon=eta-t.

Construct q* as follows:
1. Set q*_1=p_1+eta.
2. Starting from i=r and moving downward to i=2, remove total mass epsilon from p_i, never removing more than the current component:
   take_i=min(p_i, remaining_removal).
3. Set q*_i=p_i-take_i for i=2,...,r.
4. Set q*_i=0 for i>r.

Equivalently, the removed mass epsilon is taken from the smallest retained components first.

The construction is feasible because:
epsilon < 1-p_1-t = P_r-p_1 = sum_{i=2}^r p_i.

It preserves the descending order of the retained spectrum.

Its purity is the exact global maximum over F_r.

==================================================
3. PROOF BY MAJORIZATION
==================================================

For any feasible q, define:
a=sum_i(p_i-q_i)_+.
Then 0<=a<=epsilon.

Since sum_i q_i=1 and sum_{i=1}^r p_i=1-t:
sum_i(q_i-p_i)_+=t+a.

For any subset S of {1,...,r}:
q(S)-p(S)
<= sum_i(q_i-p_i)_+
=t+a
<=t+epsilon
=eta.

Therefore, for the k largest components of q:
sum_{i=1}^k q_i^down
<= P_k+eta.
Also every partial sum is at most 1, so:
sum_{i=1}^k q_i^down <= min(1,P_k+eta).

Now consider the constructed q* in Case 2.
It places all positive excess mass eta into the first component and removes epsilon from the smallest retained components first.

For every k<=r, the amount of the removed epsilon that can be taken from indices greater than k is:
min(epsilon, P_r-P_k).

Consequently:
sum_{i=1}^k q*_i
= P_k+eta-epsilon+min(epsilon,P_r-P_k)
= P_k+t+min(epsilon,P_r-P_k)
= min(1,P_k+eta).

For k>r, the partial sum of q* is 1.

Thus q* attains the upper bound on every ordered partial sum and majorizes every feasible q.

The function x -> sum_i x_i^2 is strictly Schur-convex. Therefore:
sum_i(q*_i)^2 >= sum_i(q_i^down)^2 = sum_i q_i^2
for every feasible q.

Hence q* is a global maximizer. The maximizing sorted spectrum is unique; assignments among degenerate eigenspaces may differ by permutation. QED.

Case 1 is already settled by the purity upper bound 1.

==================================================

At eta=t:
epsilon=0.
The retained components i=2,...,r are unchanged.
q*_1=p_1+t.
The entire discarded tail mass t is transferred to the largest retained eigenvalue.

At eta=1-p_1:
epsilon=P_r-p_1.
All retained components except the largest can be reduced to zero.
The result is q*=e_1, with D(p,e_1)=1-p_1.

For eta>1-p_1:
the same pure spectrum remains feasible; the distance constraint is inactive.

For r=1:
t=1-p_1, so every feasible eta satisfies eta>=1-p_1 and q*=e_1.

Degenerate largest eigenvalues:
any one of the tied largest components may receive the added mass. The resulting sorted maximizing spectrum is the same.
