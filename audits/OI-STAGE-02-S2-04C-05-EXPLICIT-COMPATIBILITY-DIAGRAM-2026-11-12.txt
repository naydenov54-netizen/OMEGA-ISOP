1. FINITE UNDERLYING STRUCTURE

Let

U0 = {a,b,c,d}.

Define an equivalence relation ~ on U0 by its two equivalence classes:

A = {a,c}
B = {b,d}.

Thus:
a ~ c, b ~ d,
and every element of A is inequivalent to every element of B.

Define the selected apartness relation # by

x # y  iff  not(x ~ y).

The relation # is symmetric and irreflexive. Each configuration below carries the induced restriction of # to its underlying subset.

2. EXPLICIT TEST CATEGORY C_U0-INC

Objects:
C(S) = (S, # restricted to S x S),

where S is a subset of U0 satisfying both:
(i) |S| >= 2;
(ii) there exist x,y in S such that x # y.

Morphisms:
A morphism C(S) -> C(T) exists exactly when S is a subset of T, and is the literal inclusion map i_{S,T}:S -> T.

Identity morphisms are literal identity inclusions.
Composition is ordinary composition of inclusions.
Associativity and identity laws follow from associativity and identity laws for functions.

This is a finite category: U0 is finite, so it has finitely many subsets and therefore finitely many objects and morphisms.

The object class is closed under unions of two or more objects: if S and T are objects, S union T contains S, and therefore retains the nontriviality witness already present in S.

3. FINITE INDEXING CATEGORY J

Let J have three objects:

Ob(J) = {0,1,2}.

Its non-identity arrows are exactly:

alpha: 0 -> 1
beta: 0 -> 2.

There are no other non-identity arrows. Together with the three identity arrows, this defines a finite category. No pair of non-identity arrows is composable.

4. DIAGRAM FUNCTOR D:J -> C_U0-INC

Define the configuration objects:

C0 = C({a,b})
C1 = C({a,b,c})
C2 = C({a,b,d}).

Each is an object:
- C0 is nontrivial because a # b.
- C1 is nontrivial because a # b.
- C2 is nontrivial because a # b.

Define D on objects by:

D(0) = C0
D(1) = C1
D(2) = C2.

Define D on non-identity arrows by:

D(alpha) = i_{C0,C1}: C0 -> C1
D(beta)  = i_{C0,C2}: C0 -> C2.

The identity arrows are mapped to the corresponding identity morphisms.

This defines a functor because the only required composition conditions involve identities, and those are preserved.

5. CANDIDATE AMALGAM AND COCONE

Define

M = C({a,b,c,d}) = C(U0).

The object M is admissible in the selected test category:
- |U0| = 4 >= 2;
- a # b.

Define the cocone maps:

j1 = i_{C1,M}: C1 -> M
j2 = i_{C2,M}: C2 -> M.

Compatibility on C0 holds:

j1 o D(alpha) = j2 o D(beta).

Both sides are the same literal inclusion C0 -> M. Hence (M,j1,j2) is a cocone over D.

6. DIRECT VERIFICATION OF THE UNIVERSAL PROPERTY

Let T be any object of C_U0-INC and suppose a cocone from D to T is given. Such a cocone consists of morphisms

u1: C1 -> T
u2: C2 -> T

satisfying

u1 o D(alpha) = u2 o D(beta).

By the definition of morphisms in C_U0-INC, u1 and u2 are literal inclusions. Their existence therefore implies:

{a,b,c} is a subset of the underlying set of T,
{a,b,d} is a subset of the underlying set of T.

Consequently,

{a,b,c,d} is a subset of the underlying set of T.

Thus there exists a morphism

u: M -> T,

and it is the literal inclusion.

Factorization:
u o j1 = u1
u o j2 = u2.

Uniqueness:
There is at most one morphism M -> T in C_U0-INC, because the only permitted morphism between two objects is the literal inclusion. Therefore u is unique.

The cocone (M,j1,j2) is consequently a colimit cocone of D in C_U0-INC. Since J is the span-shaped indexing category, this colimit is also the pushout of the span C1 <- C0 -> C2 in this selected category.
