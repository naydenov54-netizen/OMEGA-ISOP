============================================================
1. SINGLE QUESTION
============================================================

For the fixed clause and free relational span A <- C -> B
of S3.25, can Real(X) be characterized by finitely many
assignment types that account for accidental equalities
between distinct positive-equality classes?

Answer:
YES.

The exact assignment type consists of:
1. the kernel partition of the assignment on W;
2. a side-colour C, A0, or B0 on every kernel block;
3. an injective realization of the blocks by actual elements
   satisfying the relational body atoms.

Here:
A0 denotes A\C.
B0 denotes B\C.

The first two items form a finite combinatorial type.
The third is a finite-variable relational constraint
satisfaction problem over the given span.

This is exact. It does not imply that the third item is
decidable for arbitrary infinite structures.


============================================================
2. HYPOTHESES AND INHERITED NOTATION
============================================================

Retain all hypotheses of S3.25:

- a fixed finite function-free relational Horn body;
- relational body atoms A_1,...,A_k;
- positive equality premises only;
- no disequality premises;
- no negative relational premises;
- every clause variable occurs in a relational body atom;
- A and B have common induced substructure C;
- A intersect B = C;
- D is the free relational amalgam, with domain A union B
  and each relation interpreted as the union of its
  interpretations on A and B.

Let V be the finite set of clause variables.

Let ≡ be the equivalence relation generated by the positive
equality premises.

Let W = V/≡ and m = |W|.

For each atom A_i, supp(A_i) is the set of classes in W
represented by its variable positions.

For a body-satisfying assignment s, its S3.25 pattern is:

X_s = { w in W : s(w) is outside C }.

For X subset of W, Real(X) means that there exists a
body-satisfying assignment s with X_s = X.

The S3.25 active set E(X) and graph G_X remain unchanged.
In particular, accidental equality of two distinct members
of W does NOT create an edge in G_X. Edges remain defined
only by a common class in W, as in S3.24.


============================================================
3. ASSIGNMENT KERNEL
============================================================

A body-satisfying assignment s induces an equivalence
relation π_s on W:

u π_s v  iff  s(u) = s(v).

This is the kernel partition of s.

Important distinction:

- The quotient W = V/≡ identifies only equalities forced
  by positive equality premises.
- The further partition π_s identifies classes that happen
  to receive the same element under this particular
  assignment.

Thus π_s is a partition of W, not a replacement for ≡.

Every block of π_s has exactly one of three colours:

C:
The common assigned element lies in C.

A0:
The common assigned element lies in A\C.

B0:
The common assigned element lies in B\C.

These three regions are pairwise disjoint because
A intersect B = C.

A block cannot receive two colours.

Moreover, no block of π_s can contain both a member of X_s
and a member of W\X_s, because equal values have the same
membership status with respect to C.

Call (π_s, λ_s) the COLOURED KERNEL TYPE of s, where
λ_s assigns one of C, A0, B0 to each block of π_s.


============================================================
4. RELATIONAL COMPATIBILITY OF A COLOURED TYPE
============================================================

Fix a partition π of W and a colour map:

λ : Blocks(π) -> {C, A0, B0}.

A realization of (π, λ) is an injective map:

h : Blocks(π) -> A union B

such that:
- h(P) belongs to C when λ(P)=C;
- h(P) belongs to A\C when λ(P)=A0;
- h(P) belongs to B\C when λ(P)=B0;
- all relational body atoms are true when each class
  w is assigned h([w]_π).

Injectivity is required because π is the exact kernel:
different blocks must receive different elements.

For an atom R(w_1,...,w_r), its induced block tuple is:

([w_1]_π, ..., [w_r]_π).

The corresponding element tuple is:

(h([w_1]_π), ..., h([w_r]_π)).

The free-amalgam semantics gives the following local
compatibility rule.

RULE A — A-MIXED SUPPORT

If the atom tuple contains at least one A0-coloured block,
then it contains no B0-coloured block, and its element
tuple must belong to R^A.

RULE B — B-MIXED SUPPORT

If the atom tuple contains at least one B0-coloured block,
then it contains no A0-coloured block, and its element
tuple must belong to R^B.

RULE C — COMMON SUPPORT

If every block in the atom tuple is C-coloured, then its
element tuple must belong to R^C.

These rules are necessary and sufficient for that atom
to hold in the free relational amalgam.

Reason:
A tuple containing an A\C element cannot be a tuple of B.
A tuple containing a B\C element cannot be a tuple of A.
A tuple entirely in C belongs to the free union relation
exactly when it belongs to the induced common relation R^C.

For an atom containing both an A0 and a B0 block, no side
can support the tuple. Such a coloured type is therefore
immediately impossible.

Repeated coordinates are handled by repeated block IDs.
No additional assumption of distinctness between different
variable positions is made beyond the exact kernel partition.


============================================================
5. EXACT REALIZABILITY THEOREM
============================================================

THEOREM 5.1 — COLOURED KERNEL CHARACTERIZATION

For every X subset of W:

Real(X) holds if and only if there exist:
1. a partition π of W;
2. a colour map λ : Blocks(π) -> {C, A0, B0};
3. an injective realization h of (π, λ);

such that:

(i) every block P of π is contained in X or contained
    in W\X;

(ii) λ(P)=C iff P is contained in W\X;

(iii) λ(P) is either A0 or B0 iff P is contained in X;

(iv) every relational body atom satisfies the
     free-amalgam compatibility rules in Section 4.

PROOF

Forward direction:

Suppose Real(X) holds. Choose a body-satisfying assignment
s with X_s=X.

Let π=π_s be its kernel partition.

If two classes lie in the same π-block, they receive the
same element. Therefore they are either both assigned
inside C or both outside C. Hence each block lies wholly
inside X or wholly inside W\X.

Colour each π-block by the region containing its assigned
element:
C, A0, or B0.

Define h(P) to be the common value assigned to the
members of P.

Different π-blocks have different assigned values by
definition of the kernel. Thus h is injective.

Every relational body atom is true under s. Since D is
the free relational amalgam, each such tuple obeys exactly
the compatibility rules in Section 4.

Therefore (π, λ, h) satisfies (i)-(iv).

Reverse direction:

Suppose π, λ and h satisfy (i)-(iv).

Define an assignment s on W by:

s(w) = h([w]_π).

Extend it to V by assigning every variable its W-class
value.

Because h is injective, the kernel of this assignment is
exactly π.

Every positive equality premise holds because its two
variables belong to the same class in W.

By (i)-(iii), the classes assigned outside C are exactly X.
Thus X_s=X.

By (iv) and the free-amalgam compatibility rules, every
relational body atom is true in D.

Therefore s witnesses Real(X).

QED.


============================================================
6. FINITE TYPE BOUND
============================================================

Let B_m denote the m-th Bell number, the number of
partitions of an m-element set.

There are at most:

B_m * 3^m

coloured kernel types.

Reason:
There are B_m possible partitions of W.
Each partition has at most m blocks.
Each block has one of three colours.
Thus the total is bounded by B_m * 3^m.

This is an upper bound; many types are disallowed because
a block cannot cross X and W\X.

For a fixed X, only partitions that refine the two-part
partition {X, W\X} are admissible.
For every admissible partition, blocks in W\X are forced
to colour C, while blocks in X have two possible colours,
A0 or B0.

Consequently, the exact S3.25 feasibility question can
be reduced to a finite family of coloured kernel types.

The type count is independent of the cardinalities of
A, B and C.


============================================================
7. CSP FORMULATION
============================================================

For each admissible coloured kernel type (π, λ), introduce
one CSP variable z_P for each block P of π.

Its domain is:
- C, if λ(P)=C;
- A\C, if λ(P)=A0;
- B\C, if λ(P)=B0.

Add an all-different constraint over all z_P.

For every relational atom R(w_1,...,w_r), add the relation
constraint on:

(z_[w_1]_π, ..., z_[w_r]_π)

using the appropriate side relation:
- R^A if the tuple has an A0 block;
- R^B if the tuple has a B0 block;
- R^C if all its blocks are C.

Reject the type immediately if one atom contains both
an A0 and a B0 block.

Then:

Real(X) holds iff at least one admissible coloured-type
CSP has a solution.

This is an exact finite-variable CSP characterization.

For finite explicitly represented A, B and C, it gives
a decision procedure.

For infinite structures, the number of types is still
finite, but satisfiability of the resulting CSPs is not
decidable in general without further assumptions on the
structures or their relation representations.


============================================================
8. WHY MEMBERSHIP PATTERNS ALONE ARE INSUFFICIENT
============================================================

The set X records only whether each forced-equality class
is in C or outside C.

It does not record:
- whether two different classes accidentally receive
  the same element;
- whether an outside element belongs to A\C or B\C;
- whether a relation tuple can be supported by one side.

Example 8.1 — Accidental equality

Body:

R(x) AND S(y).

There are no equality premises.
Thus W={[x],[y]}.

Let C be empty and let A have one element a with:

R^A={a}
S^A={a}.

The only body-satisfying assignment has:

s(x)=s(y)=a.

Its kernel partition has one block:
π={{[x],[y]}}.

Its colour is A0.

The membership pattern is:

X=W.

The same X would also be compatible with a different
assignment in a larger structure where x and y receive
different elements. X alone cannot distinguish these
situations.

The S3.24 active graph remains two isolated vertices in
both cases, because there is no positive equality premise
identifying x and y. Accidental equality does not add an
edge.

Example 8.2 — Side colours

Body:

R(x) AND S(y).

Let C be empty.
Let A contain a tuple satisfying R(x), and B contain a
tuple satisfying S(y).

The pattern X=W is realizable, but its two blocks have
different side colours:
[x] is A0 and [y] is B0.

The assignment exists because the atoms are unary and
each is supported on its own side.

For a single atom R(x,y), however, a type assigning
[x] colour A0 and [y] colour B0 is impossible:
no side contains the mixed tuple.

Thus side colours are indispensable for exact
realizability.


============================================================
9. INTERACTION WITH S3.25 ACTIVE GRAPH
============================================================

The coloured kernel type refines Real(X), but it does not
change E(X) or G_X.

For each realizable X:

E(X) = { i : supp(A_i) intersects X }.

An edge i-j exists exactly when:

supp(A_i) intersect supp(A_j) intersect X is nonempty.

The kernel partition π_s is not used to create edges.

This distinction is deliberate:

- π_s records actual accidental equality of assigned values;
- W records equality forced by positive equality premises;
- G_X uses only the latter, as required by S3.24.

The exact S3.25 theorem therefore remains unchanged:
the active-exclusive condition is checked on every
realizable X, and realizability is now characterized by
Theorem 5.1.


============================================================
10. ADVERSARIAL TESTS
============================================================

TEST 1 — POSITIVE EQUALITY

Body:

R(x) AND S(y) AND x=y.

The positive equality quotient W has one class q.

Every assignment has the one-block kernel partition
{{q}}.

Its colour is C, A0 or B0 according to the assigned value.

The CSP representation preserves the equality bridge.
No accidental distinction between x and y is possible
because they already belong to the same W-class.

TEST 2 — ACCIDENTAL EQUALITY WITHOUT A PREMISE

Body:

R(x) AND S(y).

No equality premise.

If x and y receive the same value, π has one block.
If they receive different values, π has two blocks.

Both cases may have the same X.

The coloured kernel types distinguish them without
incorrectly adding an edge to G_X.

TEST 3 — MIXED-SIDE ATOM

Body contains:

R(x,y).

A type with [x] coloured A0 and [y] coloured B0 is
rejected immediately.

The tuple cannot belong to R^A because y is not in B's
exclusive part, and cannot belong to R^B because x is not
in B. More directly, no side contains both exclusive
elements.

TEST 4 — NEUTRAL COMMON INTERFACE ATOM

An atom whose entire tuple is assigned in C must be
checked against R^C.

It is not enough that the tuple appears in one side:
because C is induced, its restriction to C agrees with
the common relation.

The CSP rule correctly checks R^C.

TEST 5 — REPEATED VARIABLE POSITIONS

For:

R(x,x,y),

the block tuple is:

([x]_π, [x]_π, [y]_π).

The repeated coordinate is preserved.
The encoding does not replace the atom by a set of
variables or erase coordinate multiplicity.

TEST 6 — INFINITE C

The finite type construction and Theorem 5.1 remain valid
for infinite C.

The CSP domains may be infinite, so the finite type
reduction does not by itself decide whether a type has
a realization.


============================================================
11. WHAT THIS RESULT DOES NOT PROVE
============================================================

Theorem 5.1 is an exact characterization of Real(X) for
a fixed finite clause and a fixed free relational span.

It does NOT prove:

1. that Real(X) is determined by X alone;
2. that side labels and kernel partitions eliminate the
   need to inspect relation interpretations;
3. decidability over arbitrary infinite structures;
4. a span-independent syntactic criterion for all spans;
5. necessity of active-exclusive connectivity for Horn
   preservation;
6. a necessary-and-sufficient characterization of all
   Horn theories preserved by free amalgamation;
7. applicability to the full canonical S3-C3 class.

The all-different constraint is essential. Omitting it
would allow two distinct kernel blocks to receive the
same element, thereby changing the claimed kernel and
making the reverse direction inexact.

The inducedness of C is also essential for the
all-C atom rule using R^C.
