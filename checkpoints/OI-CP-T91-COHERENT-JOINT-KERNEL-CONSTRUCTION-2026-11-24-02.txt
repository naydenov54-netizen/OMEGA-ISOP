1. OBJECTIVE AND BOUNDARY
============================================================

The parent checkpoint established that pairwise coupling feasibility does not imply global joint coherence. The present checkpoint constructs a positive example in which a single family of joint kernels is globally coherent.

The construction is a sufficient example, not a theorem that every Markov kernel admits a relation-preserving coherent lift.

============================================================
2. FINITE CONSTRUCTION
============================================================

Let:
X = {0,1}
and let g:X->X be the complement involution:
g(0)=1
g(1)=0
g(g(x))=x.

Fix p in [0,1]. Define the one-coordinate Markov kernel:
kappa(x,.) = (1-p) delta_x + p delta_g(x).

Equivalently:
kappa(0,{0})=1-p
kappa(0,{1})=p
kappa(1,{1})=1-p
kappa(1,{0})=p.

For every n>=1 and every input tuple xbar=(x1,...,xn), define:
Lambda_n(xbar,.) =
(1-p) delta_(x1,...,xn)
+ p delta_(g(x1),...,g(xn)).

MARGINAL CHECK:
For each coordinate i:
Marginal_i(Lambda_n(xbar,.))
= (1-p)delta_xi + p delta_g(xi)
= kappa(xi,.).

Thus every coordinate has the prescribed Markov marginal.

RELATIONAL PRESERVATION:
Consider the binary relations:
Eq = {(0,0),(1,1)}
Neq = {(0,1),(1,0)}.

The diagonal complement action preserves both:
(x,y) in Eq => (g(x),g(y)) in Eq;
(x,y) in Neq => (g(x),g(y)) in Neq.

Therefore, if the input tuple satisfies any coordinatewise Eq/Neq constraints, both support points of Lambda_n satisfy the same constraints. Hence the joint kernel is supported on every such relation constraint that holds at the input.

This is not independent product sampling. All coordinates use the same random bit.

============================================================
3. GLOBAL COHERENCE CHECKS
============================================================

PROJECTIVE CONSISTENCY:
For any coordinate projection pi_I:
(pi_I)_* Lambda_n(xbar,.)
= Lambda_|I|(pi_I(xbar),.).

This follows because projecting either xbar or its simultaneous complement gives the corresponding projected tuple or its simultaneous complement.

PERMUTATION EQUIVARIANCE:
For any permutation s of the coordinates:
s_* Lambda_n(xbar,.)
= Lambda_n(s(xbar),.).

MARGINAL COMPATIBILITY:
Every one-coordinate marginal equals kappa(x_i,.), for every n and every coordinate i.

COMMON-NOISE REALIZATION:
Let Z be a Bernoulli(p) random variable shared by all coordinates and define:
Y_i = x_i if Z=0;
Y_i = g(x_i) if Z=1.

Then the joint law of (Y_1,...,Y_n) is Lambda_n(xbar,.). This one shared random variable produces the entire compatible family. No separately selected pairwise couplings are needed.

The construction therefore avoids the parent checkpoint's pairwise-versus-global coherence obstruction for this selected relational signature.

4. MEASURABLE GENERALIZATION
============================================================

Let (X,Sigma_X) be a measurable space and let:
g:X->X
be a measurable involution:
g(g(x))=x.

Fix p in [0,1] and define:
kappa(x,.)=(1-p)delta_x+p delta_g(x).

For every finite n define:
Lambda_n(x1,...,xn;.)
=(1-p)delta_(x1,...,xn)
+p delta_(g(x1),...,g(xn)).

For each coordinate i, the marginal is kappa(x_i,.).

For every finite-arity relation rho subseteq X^n satisfying diagonal g-invariance:
(x1,...,xn) in rho
=> (g(x1),...,g(xn)) in rho,
the joint kernel is supported on rho whenever the input tuple belongs to rho.

Measurability:
The identity map and g are measurable. The corresponding Dirac kernels are measurable, and a fixed convex combination of these kernels is measurable. Thus Lambda_n is a measurable probability kernel on the product measurable space, under the standard product-measurability assumptions.

The family is projectively consistent and permutation-equivariant by direct calculation.

This gives a measurable coherent lift for the restricted class of relational signatures invariant under the same diagonal involution.

============================================================
5. RELATION TO THE RANDOMIZATION LEMMA
============================================================

For standard Borel target spaces, a Markov kernel can be represented by a jointly measurable map driven by a uniform random variable (randomization lemma).

This general representation fact does NOT imply relational preservation.

The additional condition needed here is that the same noise variable is used across coordinates and that, for almost every noise value, the resulting coordinate map preserves every relation in the selected signature.

In the present construction:
F_0(x)=x
F_1(x)=g(x).

Both maps preserve the selected relations. The shared Bernoulli variable selects between them.

Therefore the measurable construction is stronger than merely representing each marginal kernel separately.

REFERENCE:
Kolokoltsov, V. N., probability/analysis text, Randomization Lemma 1.1.1, available at:
https://warwick.ac.uk/fac/sci/statistics/staff/academic-research/kolokoltsov/books/markhead.pdf
The cited lemma supports measurable randomization of a kernel on Borel spaces; it does not assert relation preservation.
