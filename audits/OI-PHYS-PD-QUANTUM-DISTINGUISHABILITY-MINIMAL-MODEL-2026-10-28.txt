2. MODEL AND EXPLICIT INPUTS

Use a two-level quantum system (qubit) with initial pure state |psi(0)> = |0>. Assume unitary evolution
U(t) = exp(-i omega t sigma_y / 2),
where omega is a specified angular frequency and sigma_y is the Pauli-y operator.

This dynamics, the quantum state space, the Born rule, and the operational measurement framework are physical/theoretical inputs. They are not derived from PD-A or from the formal apartness relation. The model is a test realization, not a claim that quantum mechanics follows from OMEGA-ISOP.

The evolved state is
|psi(t)> = cos(omega t/2)|0> + sin(omega t/2)|1>.

3. DERIVED QUANTITATIVE RESULT

For pure states rho_0 = |0><0| and rho_t = |psi(t)><psi(t)|, define trace distance
D(rho_0,rho_t) = (1/2)||rho_0-rho_t||_1.

For pure states, D = sqrt(1 - |<psi(0)|psi(t)>|^2). Since |<psi(0)|psi(t)>| = |cos(omega t/2)|,
D(t) = |sin(omega t/2)|.

For equal prior probabilities, the optimal single-shot success probability for discriminating the two states is
P_succ(t) = (1 + D(t))/2.
Therefore
P_succ(t) = (1 + |sin(omega t/2)|)/2.

This is a conditional mathematical consequence of the stated quantum model and the standard optimal state-discrimination result. It is not a consequence of PD-A alone.

4. THRESHOLD APARTNESS

For a chosen threshold 0 < epsilon <= 1, define an operational relation
rho_0 #_epsilon rho_t iff D(rho_0,rho_t) >= epsilon.

Then the criterion is
|sin(omega t/2)| >= epsilon.

For times in a range where 0 <= omega t <= pi, this is equivalent to
t >= (2/omega) arcsin(epsilon),
provided omega > 0 and the interval includes the threshold time.

The threshold epsilon is an operational choice determined by the discrimination requirement and experimental context; it is not selected by PD-A.
