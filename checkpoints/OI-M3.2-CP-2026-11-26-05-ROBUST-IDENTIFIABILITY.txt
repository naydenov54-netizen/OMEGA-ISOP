2. MODEL AND ASSUMPTIONS
==================================================
State space: S = {00, 01, 10, 11}.
Parameters: alpha = c + epsilon; beta = c - epsilon.
Observation functional: r(mu) = alpha*mu00 + beta*mu10.
Known preparations: mu and nu.
Preparation constraints:
mu00 >= 0; mu10 >= 0; mu00 + mu10 <= 1.
nu00 >= 0; nu10 >= 0; nu00 + nu10 <= 1.
The remaining coordinates are nonnegative and complete normalization to one.
Two measured scalar values are r(mu) and r(nu).

Define:
A = [[mu00, mu10], [nu00, nu10]]
theta = [alpha, beta]^T
y = [r(mu), r(nu)]^T
D = mu00*nu10 - nu00*mu10

Exact observation equation:
y = A*theta.
Noisy observation equation:
y_obs = A*theta + eta, where eta = [eta1, eta2]^T.
The preparation matrix A is assumed known exactly in this checkpoint. Preparation uncertainty is not yet included.

==================================================
3. EXPERIMENT 13A — EXACT ERROR PROPAGATION
==================================================
For D != 0:
A^(-1) = (1/D)*[[nu10, -mu10], [-nu00, mu00]].

The estimator based on the observed values is:
theta_est = A^(-1)*y_obs.

Therefore:
theta_est - theta = A^(-1)*eta.

Componentwise:
Delta_alpha = (nu10*eta1 - mu10*eta2)/D.
Delta_beta = (-nu00*eta1 + mu00*eta2)/D.

This identity is exact for the stated linear model and exact knowledge of A.

==================================================
4. EXPERIMENT 13B — BOUNDED DETERMINISTIC NOISE
==================================================
Assume:
|eta1| <= delta and |eta2| <= delta.

Then:
|Delta_alpha| <= delta*(|nu10| + |mu10|)/|D|.
|Delta_beta| <= delta*(|nu00| + |mu00|)/|D|.

Thus small |D| can amplify bounded observation errors. These are deterministic worst-case bounds; no probability distribution is assumed.

==================================================
5. EXPERIMENT 13C — SPECTRAL SENSITIVITY
==================================================
Define:
F = mu00^2 + mu10^2 + nu00^2 + nu10^2.

The squared singular values of A are the roots of:
lambda^2 - F*lambda + D^2 = 0.

Hence the largest eigenvalue of A^T*A is:
lambda_max = (F + sqrt(F^2 - 4*D^2))/2.

For D != 0:
||A^(-1)||2 = sqrt((F + sqrt(F^2 - 4*D^2))/(2*D^2)).

Therefore:
||theta_est - theta||2 <= ||A^(-1)||2 * ||eta||2.

This is the exact induced Euclidean-norm sensitivity factor for the inverse map. It is not an empirical noise estimate.

==================================================
6. EXPERIMENT 13D — OPTIMAL PREPARATION DESIGN
==================================================
Under the preparation constraints, all four entries of A are nonnegative and each row sum is at most one.

By the triangle inequality:
|D| = |mu00*nu10 - nu00*mu10|
     <= mu00*nu10 + nu00*mu10
     <= (mu00 + mu10)*(nu00 + nu10)
     <= 1.

The bound is attained by:
mu = (1,0,0,0)
nu = (0,0,1,0)

For these preparations:
A = [[1,0],[0,1]]
D = 1
A^(-1) = I
kappa2(A) = 1
||A^(-1)||2 = 1.

Since every invertible matrix has spectral condition number kappa2(A) >= 1, this design is optimally conditioned. It also attains the maximum possible absolute determinant over the stated preparation domain.

The observations become:
r(mu) = alpha
r(nu) = beta.

Consequently:
Delta_alpha = eta1
Delta_beta = eta2.

No amplification occurs in the two parameter coordinates for this design.
