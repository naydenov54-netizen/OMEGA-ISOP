============================================================
1. PURPOSE AND BOUNDARY
============================================================

This checkpoint records an audit of a Markov-kernel generalization of the measurable pushforward realization used in the conditional analysis of Theorem 91.

The audit separates:
(A) the measure-theoretic construction and derivation of H3;
(B) closure of the operational language;
(C) non-expansion of operational distance;
(D) preservation of the structural constraints R;
(E) compatibility with the canonical realization Phi.

A result in (A)-(C) does not establish (D) or (E). No universal generalization of Theorem 91 is claimed.

============================================================
2. MEASURABLE AND MARKOV SETUP
============================================================

Let (X, Sigma_X) be a measurable space.

A Markov kernel is:
kappa : X x Sigma_X -> [0,1]

such that:
1. For each x in X, kappa(x,.) is a probability measure on (X,Sigma_X).
2. For each E in Sigma_X, x -> kappa(x,E) is Sigma_X-measurable.

For a probability measure mu on (X,Sigma_X), define:
(mu kappa)(E) := integral_X kappa(x,E) dmu(x).

Then mu kappa is a probability measure on (X,Sigma_X).

Use the measurable model notation:
M_mu := (X, Sigma_X, R, mu).

For a fixed kernel kappa, define the measure-level transformation:
T_hat_kappa(M_mu) := M_(mu kappa)
                  = (X, Sigma_X, R, mu kappa).

This construction updates the measure component. It does not, by itself, prove that R is preserved under a probabilistic transition. The displayed definition is a valid model transformation only in a model class closed under this measure update and subject to whatever independent structural-admissibility conditions are imposed.

============================================================
3. MARKOV OPERATOR AND DERIVATION OF H3
============================================================

For bounded Sigma_X-measurable a : X -> R, define:
P_kappa(a)(x) := integral_X a(y) kappa(x,dy).

The Markov-kernel integration identity gives:
integral_X a(y) d(mu kappa)(y)
= integral_X [integral_X a(y) kappa(x,dy)] dmu(x)
= integral_X P_kappa(a)(x) dmu(x).

Define response:
Resp_(M_mu)(a) := integral_X a(x) dmu(x).

Therefore:
Resp_(T_hat_kappa(M_mu))(a)
= Resp_(M_mu)(P_kappa(a)).

Set:
tau(a) := P_kappa(a).

Then:
Resp_(T_hat_kappa(M_mu))(a)
= Resp_(M_mu)(tau(a)).

Thus H3 is DERIVED in this fixed-kernel measurable probability realization, provided tau is an endomap of the operational language and the same kernel is used for every model in the comparison class.

This is not a derivation for arbitrary model realizations or arbitrary operational languages.

============================================================
4. CONDITIONS REQUIRED
============================================================

K1. COMMON KERNEL:
The same kappa must define the transformation for every model in the comparison class. If kernels depend on the model, tau_M = P_(kappa_M) is generally model-dependent. A common tau requires a separate proof that the induced operators agree on L_op or otherwise define one common endomap.

K2. OPERATIONAL CLOSURE:
P_kappa(L_op) subseteq L_op.
This is not automatic for an arbitrary subset L_op of bounded measurable functions.

K3. MEASURABILITY AND INTEGRABILITY:
For bounded measurable a, P_kappa(a) is measurable and bounded, and the iterated-integral identity applies. For unbounded observables, additional integrability hypotheses are needed.

K4. MODEL-CLASS CLOSURE:
The model class must contain M_(mu kappa) whenever it contains M_mu. If additional restrictions are imposed on admissible measures, closure must be separately established.

K5. STRUCTURAL ADMISSIBILITY:
The probabilistic transition must preserve or validly transform the structural constraints R under an explicitly defined probabilistic relational semantics. This is not implied by the Markov-kernel axioms.

K6. CANONICAL COMPATIBILITY:
It remains to prove that the canonical realization Phi selects or admits this measurable Markov construction, that its canonical L_op is represented by functions on X, and that K1-K5 hold for the canonical class.

============================================================
5. OPERATOR FACTS
============================================================

On B_b(X), the bounded measurable real-valued functions, P_kappa is:
- positivity preserving;
- constant preserving: P_kappa(1)=1;
- a contraction in supremum norm:
  ||P_kappa(a)||_infinity <= ||a||_infinity.

These facts do not imply P_kappa(L_op) subseteq L_op for an arbitrary subspace or subset L_op.

============================================================
6. COUNTEREXAMPLE TO AUTOMATIC OPERATIONAL CLOSURE
============================================================

Let X={0,1}. Let kappa be the state-independent uniform kernel:
kappa(0,{0})=kappa(0,{1})=1/2,
kappa(1,{0})=kappa(1,{1})=1/2.

Let L_op={a}, where:
a(0)=0,
a(1)=1.

Then:
P_kappa(a)(0)=1/2,
P_kappa(a)(1)=1/2.

Hence P_kappa(a) is the constant function 1/2, which is not in L_op.

Therefore:
P_kappa(L_op) is not a subset of L_op.

So the Markov-kernel axioms alone do not provide tau : L_op -> L_op and do not establish H3 in the required common operational language.

============================================================
7. NON-EXPANSION
============================================================

Assume:
- a common kappa is used for all models;
- tau=P_kappa;
- P_kappa(L_op) subseteq L_op;
- the response identity derived in Section 3 holds.

Then:
D_L(T_hat_kappa(M1), T_hat_kappa(M2))
= sup_(a in L_op) ||Resp_(M1)(tau(a))-Resp_(M2)(tau(a))||
<= sup_(b in L_op) ||Resp_(M1)(b)-Resp_(M2)(b)||.

Therefore:
D_L(T_hat_kappa(M1), T_hat_kappa(M2))
<= D_L(M1,M2).

Surjectivity of tau is not required. If L_op consists of bounded probes and the responses are probability expectations, the distance is finite; it is generally a pseudometric unless L_op separates the compared models.

============================================================
8. DETERMINISTIC KERNEL AS SPECIAL CASE
============================================================

For a measurable map T:X->X, define:
kappa_T(x,E) := 1_E(T(x)).

Then:
P_(kappa_T)(a)(x)=a(T(x)).

Thus:
P_(kappa_T)(a)=a o T.

The deterministic measurable pushforward construction is recovered as a special case of the Markov-kernel construction.

This inclusion does not establish that every Markov kernel is structurally admissible in OMEGA-ISOP.

============================================================
9. STRUCTURAL RELATION PRESERVATION: OPEN OBSTRUCTION
============================================================

A deterministic state map can preserve an n-ary relation rho through pointwise preservation:
(x1,...,xn) in rho
implies
(T(x1),...,T(xn)) in rho.

A Markov kernel does not assign a unique successor state to x. It assigns a probability distribution. Therefore a statement that a kernel "preserves rho" is incomplete until a probabilistic relational semantics is specified.

Possible distinct approaches include:
1. Support-based preservation conditions.
2. Distributional relational semantics on probability measures.
3. An enriched relational/model structure whose semantics explicitly includes probabilistic transitions.

These approaches are not interchangeable. No one of them is selected here as canonical. Ordinary Markov-kernel axioms do not imply relational endomorphism or compatibility with Phi.
