boundary = mu_2 - w

3. NORMALIZED COORDINATE AND EXACT-BOUNDARY CASE
======================================================================

For the stated bump coordinate:

s(t) = (t-mu_2)/w

Using boundary = mu_2-w:

s(t) = (t-boundary)/w - 1

If the starting time is the exact rational boundary and the interval is
[b, b+eta], with:

b = boundary
eta = 1/10
w = 13/20

then:

eta/w = (1/10)/(13/20) = 2/13

Consequently:

s([b,b+eta]) = [-1, -1+2/13]
             = [-1, -11/13]

Thus:

11/13 <= |s(t)| <= 1

and:

1 - eta/w = 1 - 2/13 = 11/13

This establishes the normalized boundary-strip relation for the
EXACT-BOUNDARY, EXACT-TIME model.

The majorant algebra then gives:

rho = 2/13
rmax = 2*rho-rho^2 = 48/169
1/rmax = 169/48
U = exp(-169/48)
U approximately 0.029574779246646133

This is the nominal analytical value with boundaryWidth = 0.
It is not the actual interval-valued CAPD result.

4. INTERVAL BOUNDARY CASE: NECESSARY QUALIFICATION
======================================================================

The source construction uses an interval boundary B=[b_lower,b_upper],
not necessarily the exact point b.

Assume, to be verified from the actual interval endpoints:

b in B
and
boundaryWidth = b_upper-b_lower >= 0.

The full time hull associated with a start-time interval B and a
duration eta is:

T_hull = [b_lower, b_upper+eta].

This hull may contain times t < b. For such times, if the bump is
defined to vanish outside its support, the bump contribution is zero.
The normalized coordinate may satisfy s(t) < -1 there; it is therefore
incorrect to claim that the entire hull T_hull maps exactly into
[-1,-11/13].

For the portion at or to the right of the exact boundary:

T_inside = [b, b_upper+eta],

we have:

0 <= t-b <= eta+boundaryWidth = hEff.

Therefore:

-1 <= s(t) <= -1 + hEff/w.

Define:

rho_eff = hEff/w
        = (eta+boundaryWidth)/w.

If:

0 < rho_eff < 1,

then:

-1 <= s(t) <= -(1-rho_eff)

and equivalently:

1-rho_eff <= |s(t)| <= 1.

This proves the required strip inclusion for the inside-support
portion, subject to:
1. b is contained in B;
2. the actual time set is contained in T_hull;
3. the profile support and zero-extension definitions are as stated;
4. the solver's actual time semantics agree with this interval model.

The outside-support portion must be handled separately by proving
that the profile is exactly zero there.

This is the correct interval-geometric decomposition. The entire
interval hull must not be described as lying in the support strip.

======================================================================
5. GENERALIZED MAJORANT
======================================================================

For 0 < rho_eff < 1, set:

rmax_eff = 2*rho_eff-rho_eff^2
U_eff = exp(-1/rmax_eff).

On the inside-support strip:

1-rho_eff <= |s| <= 1,

we obtain:

s^2 >= (1-rho_eff)^2
1-s^2 <= 1-(1-rho_eff)^2
1-s^2 <= 2*rho_eff-rho_eff^2
1/(1-s^2) >= 1/rmax_eff

and hence:

exp(-1/(1-s^2)) <= exp(-1/rmax_eff) = U_eff.

At |s|=1, the bump is interpreted by its zero boundary extension;
the displayed interior expression has a limiting value of zero there.

For boundaryWidth = 0 and eta=1/10:

rho_eff = 2/13
rmax_eff = 48/169
U_eff = exp(-169/48)
U_eff approximately 0.029574779246646133.

For positive boundaryWidth, rho_eff is larger than 2/13.
While 0<rho_eff<1, rmax_eff increases with rho_eff and U_eff also
increases. Therefore the nominal value is not an upper bound for the
actual interval-width construction unless boundaryWidth is zero.

The actual interval value of boundaryWidth and the outward-rounded
CAPD evaluation remain uncomputed.
