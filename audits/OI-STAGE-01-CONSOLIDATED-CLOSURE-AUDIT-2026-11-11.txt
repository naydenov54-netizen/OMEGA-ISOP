2. FORMAL OBJECT UNDER REVIEW

The primary candidate declares:
- X: a nonempty set;
- I: a set of feature indices;
- V_i: a set of values for each i in I;
- f_i:X→V_i: a feature map for each i.

It defines:
D:X×X→{0,1}
D(x,y)=1 iff there exists i∈I such that f_i(x)≠f_i(y).
D(x,y)=0 iff for every i∈I, f_i(x)=f_i(y).

The combined signature is:
F:X→∏_{i∈I}V_i
F(x)=(f_i(x))_{i∈I}.

Therefore:
D(x,y)=1 iff F(x)≠F(y).
D(x,y)=0 iff F(x)=F(y).

The feature family and maps are explicit model inputs. The candidate does not claim that the Frozen Core uniquely determines them.

3. CONSOLIDATED MATHEMATICAL VERIFICATION

3.1 Well-definedness and edge cases — PASS

Given the declared sets and total maps f_i:X→V_i, the predicate is well-defined and has the declared codomain {0,1}.

For I=∅, the existential condition is false for every pair, so D≡0. The empty feature family is a valid degenerate model and yields no positive distinctions.

Finite and arbitrary set-sized feature families are covered. No finiteness assumption is required.

The primary candidate retains X≠∅. Tasks 04 and 05 correctly extend the abstract classification to X=∅ as a supplementary mathematical case. This does not silently change the primary candidate's domain assumption.

STATUS: PROVED FOR THE DECLARED SET-THEORETIC SETUP.

3.2 Irreflexivity and symmetry — PASS

For every x and every i, f_i(x)=f_i(x), so no feature witnesses D(x,x)=1. Thus D(x,x)=0.

Equality inequality is symmetric: f_i(x)≠f_i(y) iff f_i(y)≠f_i(x). Thus D(x,y)=D(y,x).

STATUS: PROVED.

3.3 Zero-kernel and signature separation — PASS

D(x,y)=0 iff F(x)=F(y).

Consequently, D(x,y)=0 iff x=y exactly when F is injective. Equivalently, D is a metric rather than a pseudometric exactly when F is injective, under the {0,1}-valued distance interpretation.

Without injectivity, D(x,y)=0 means equality of selected signatures, not identity of elements.

STATUS: PROVED.

3.4 Cotransitivity and logical scope — PASS WITH EXPLICIT CLASSICAL SCOPE

Assume D(x,y)=1 and choose i with f_i(x)≠f_i(y). For any z, classical logic gives either f_i(x)≠f_i(z), which yields D(x,z)=1, or f_i(x)=f_i(z), which yields f_i(z)≠f_i(y) and D(z,y)=1.

Therefore:
D(x,y)=1 ⇒ D(x,z)=1 OR D(z,y)=1.

The proof is valid in classical set theory. It is not an unrestricted constructive proof for arbitrary codomains with undecidable equality. A constructive presentation would require decidable equality or an appropriate apartness/witness structure.

STATUS: PROVED IN CLASSICAL SET THEORY; CONSTRUCTIVE GENERALIZATION NOT CLAIMED.

3.5 Pseudometric property — PASS

For all x,y,z:
D(x,y)≥0;
D(x,y)=D(y,x);
D(x,x)=0;
D(x,z)≤D(x,y)+D(y,z).

For the triangle inequality, if D(x,z)=0 the inequality is immediate. If D(x,z)=1, a feature witnesses f_i(x)≠f_i(z). It is impossible for both f_i(x)=f_i(y) and f_i(y)=f_i(z), so at least one of D(x,y), D(y,z) equals 1.

Thus D is a pseudometric. It is a metric iff F is injective. The finite counterexample to transitivity of positive difference does not contradict the triangle inequality.

STATUS: PROVED.

3.6 Positive-difference non-transitivity — PASS

The finite model X={a,b,c}, f(a)=0, f(b)=1, f(c)=0 gives:
D(a,b)=1;
D(b,c)=1;
D(a,c)=0.

This proves that positive Difference need not be transitive. It does not assert that every admissible D is non-transitive.

STATUS: VALID COUNTEREXAMPLE.

3.7 Representation invariance and quotient factorization — PASS

For two signature maps sigma_1 and sigma_2 on the same X:
D_1=D_2 iff
sigma_1(x)=sigma_1(y) exactly when sigma_2(x)=sigma_2(y), for all x,y.

Thus the induced equality-kernel equivalence relation, not the raw coordinate representation, determines D.

For x~y iff D(x,y)=0, the quotient Q=X/~ is well-defined. The signature factors as:
sigma = sigma_bar composed with q,
where q:X→Q is the quotient map and sigma_bar is injective.

This factorization is canonical relative to the selected D. It is not an ontological claim about Q.

STATUS: PROVED.

3.8 Feature addition/removal — PASS

Retaining all old coordinates and adding features can only preserve or increase positive distinguishability:
D_I(x,y)≤D_J(x,y) when I⊆J.

Removing features can only preserve or decrease positive distinguishability:
D_K(x,y)≤D_I(x,y) when K⊆I.

The inequalities are pointwise in {0,1}. The audit correctly notes that adding a feature need not change D if it separates no previously indistinguishable pair, and removing a feature need not change D if it is redundant.

STATUS: PROVED.

3.9 Primitive predicate axioms and characterization — PASS

For a primitive predicate D:X×X→{0,1}, the axioms:
A1: D(x,x)=0;
A2: D(x,y)=D(y,x);
A3: D(x,z)=1 ⇒ D(x,y)=1 OR D(y,z)=1;

are equivalent to the assertion that x~y iff D(x,y)=0 is an equivalence relation.

A1 gives reflexivity of ~. A2 gives symmetry. A3 gives transitivity by contradiction using the two-valued codomain. Conversely, reflexivity, symmetry, and transitivity of ~ imply A1–A3.

Every such primitive D has a quotient-signature representation using q:X→X/~:
D(x,y)=1 iff q(x)≠q(y).

This converse is a representation theorem in classical set theory, not a derivation of the candidate feature family from Primitive Difference PD.

STATUS: PROVED.

3.10 Independence of A1, A2, A3 — PASS WITH MODEL-CLASS SCOPE

Task 04 supplies a valid countermodel for each axiom while satisfying the other two:
- A1: singleton carrier with D(a,a)=1;
- A2: two-element asymmetric predicate with zero diagonal and the stated cotransitivity checks;
- A3: symmetric predicate with D(a,c)=D(c,a)=1 and all other values zero.

Therefore the axioms are independent over the class of all set-theoretic models with varying carrier X.

This does not mean they are independent on every fixed carrier, and it does not establish absolute syntactic minimality or a genuinely weaker alternative axiom language.

STATUS: INDEPENDENCE PROVED FOR THE DECLARED MODEL CLASS; ABSOLUTE MINIMALITY NOT ESTABLISHED.

3.11 Partition classification and cardinal claims — PASS

For every set X, admissible binary predicates satisfying A1–A3 are in bijection with partitions of X:
D_ADM(X) ≅ PART(X).

The construction from D uses its zero-equivalence classes. The reverse construction assigns D(x,y)=0 exactly when x and y lie in the same partition block.

The bijection does not require the axiom of choice.

For finite |X|=n, the number of admissible predicates is the Bell number B_n.

For infinite |X|=κ, the claim |D_ADM(X)|=2^κ is correctly stated in ZFC. The audit identifies the cardinal arithmetic and choice-dependent steps. The quotient-block bound and the converse isomorphism classification by the multiset of block cardinalities are also correctly scoped to ZFC.

STATUS: BASIC BIJECTION PROVED WITHOUT AC; CARDINAL/ISOMORPHISM RESULTS PROVED IN ZFC AS LABELLED.

3.12 Relation underdetermination — PASS WITH SCOPE LIMITATION

The finite examples show that multiple distinct directed relations can be subsets of the same D-positive support. Therefore D alone does not uniquely select an orientation or a unique directed relation under the stated compatibility rule.

This is a non-uniqueness result, not a claim that richer data or additional axioms can never define a relation.

STATUS: PROVED FOR THE STATED NON-UNIQUENESS CLAIM.

4. SOURCE-COMPATIBILITY REVIEW

4.1 PD is not D and is not #

The protected Volume II source identifies Primitive Difference PD as a meta-level condition establishing the admissibility of formal distinction. It separately introduces a carrier U0 and a selected apartness realization # on U0.

Accordingly:
PD ≠ D.
PD ≠ #.
D is a candidate binary predicate defined from a selected carrier, feature family, and feature maps. It can serve as one formal apartness-style realization under the stated axioms, but it is not Primitive Difference itself.

STATUS: COMPATIBLE ONLY WHEN THIS DISTINCTION IS PRESERVED.

4.2 Conditional compatibility with apartness and quotient structure

The candidate D satisfies the standard irreflexive, symmetric, cotransitive apartness example in classical set theory. Its zero-kernel quotient is mathematically compatible with the conditional quotient construction in Volume II, provided D is treated as the selected realization on the declared carrier.

This does not prove X=U0, D=# in the canonical Core, or that the candidate signature is uniquely selected by the Core.

STATUS: CONDITIONAL COMPATIBILITY; CANONICAL IDENTIFICATION NOT ESTABLISHED.

4.3 Nontriviality boundary

X≠∅ does not imply |X|≥2, does not imply that any pair is D-positive, and does not imply a nontrivial physical configuration. A constant signature on a nonempty X gives D≡0.

The Volume II condition |S_C|≥2 applies to a minimal nontrivial local configuration and must not be transferred to every candidate carrier X.

STATUS: BOUNDARY PRESERVED.

4.4 Stage 1 D versus Core relational structure R

The 1-valued extension of D is itself a binary relation in standard mathematical terminology. Stage 2 therefore cannot be described as the first appearance of a binary relation in any general mathematical sense.

The structural boundary is:
- Stage 1: symmetric distinguishability/apartness predicate, its zero-kernel, and the induced partition/quotient.
- Stage 2: additional relational structure not uniquely determined by D, including any required orientation, compatibility data, configuration diagram, and the Core construction R:=colim(D_CC) when the relevant categorical structure and colimit exist.

D does not derive or replace the Core compatibility-colimit R.

STATUS: BOUNDARY CLARIFIED; NO ARCHITECTURAL REWRITE.
